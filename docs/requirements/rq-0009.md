# RQ-0009 — The application's own chrome can be got out of the way

With a project open, the sidebar is a 224-pixel column carrying a name, two links and a way to close
the project. Everything else in the window is doing work: the record, the conversation, the files. The
column is not wrong — Settings has to be reachable with no project open, and the project's identity
has to live somewhere — it is simply larger than what it holds, all the time, whether or not anyone
is looking at it.

The two side rails already collapse. The one piece of chrome that cannot is the one with the least in
it, which is the wrong way round.

## Acceptance criteria

- [AC-1] The sidebar can be collapsed and restored, and stays where it was left across restarts.
- [AC-2] Collapsed, it takes no width at all, and there is a visible way to bring it back that does not
  require knowing a shortcut.
- [AC-3] It can be toggled from the keyboard, by the shortcut that does this in the tools this sits
  beside, offered in the menu where it can be found.
- [AC-4] Collapsing it changes nothing else about the layout: the panes the user sized stay sized.

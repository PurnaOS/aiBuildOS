# RQ-0043 — Playbooks live in the composer

The playbook strip is a permanent row of chrome for an occasional act, and the COMMANDS chip is a
second one for the same kind of thing from a different source. Both die. Starting a playbook or an
agent command becomes what it is — a way of composing a message — so it lives where messages are
composed: a `+` menu on the composer, and starter cards when there is nothing else to show. The
pure composition modules (`playbooks.ts`) already do the work and do not change.

## Acceptance criteria

- [AC-1] The composer's `+` menu lists the playbooks in a Playbooks section and the agent's
  commands in a Commands section; choosing one composes exactly what the strip or chip composed.
- [AC-2] PlaybookStrip and the COMMANDS chip are gone; no permanent strip of playbook or command
  chrome remains.
- [AC-3] An empty transcript shows the playbooks as centred starter cards; picking a card starts
  that playbook.
- [AC-4] The intake playbook still opens the idea prompt before composing.

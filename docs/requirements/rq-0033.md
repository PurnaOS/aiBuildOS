# RQ-0033 — Branch and sync visibility

Sync verbs without sync facts are a guess: whether to push, whether a pull is due, which branch is
even current. The git pane gains a slim sync header — current branch, ahead/behind, the Push and
Pull actions — and the application can enumerate every local branch with its upstream and its
ahead/behind counts. No upstream is a distinct fact from "in sync": counts for an unpublished
branch are absent, never rendered as zero.

## Acceptance criteria

- [AC-1] The git pane shows a sync header naming the current branch with its ahead/behind counts
  and offering Push and Pull.
- [AC-2] Every local branch can be listed with its upstream and its ahead/behind counts in one
  enumeration.
- [AC-3] A branch with no upstream shows no counts — absent, distinguishable from `↑0 ↓0`.
- [AC-4] The header's counts follow the facts: a commit, push, pull or fetch changes them without a
  refresh being pressed.

# RQ-0026 — The workspace notices every change as it happens

Every screen claims to be a live look at the project's files, and until now "live" meant "as of
the last turn's end, if the write went through this application". A terminal commit, another
editor's save, an agent's work four minutes into a turn — invisible. [DC-0022](../decisions/dc-0022.md)
settles the mechanism: main watches the open project, one debounced event, the same revision
counter on the other end, and the redundant turn-end bumps retired rather than doubled.

## Acceptance criteria

- [AC-1] A file written by anything — the agent mid-turn, a terminal, another editor — appears in
  the rails, boards and open views within a debounce, with no turn ending and nothing pressed.
- [AC-2] A state changed on disk moves its card and rail row the same way.
- [AC-3] A commit made outside the application reaches the Git tab's counts and history.
- [AC-4] Ignored trees (`node_modules`, `.git`'s object store, build output) wake nothing.
- [AC-5] The turn-end refresh paths stop bumping — one change, one refresh, not three.
- [AC-6] The record read answers from cache when nothing under `docs/` changed since it last
  parsed; a change invalidates it.
- [AC-7] Closing the project or quitting stops the watching; nothing watches a project nobody
  has open.

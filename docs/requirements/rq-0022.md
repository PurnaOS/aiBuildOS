# RQ-0022 — How closely to supervise is a setting, not a fight

The vision doc promises the choice upfront: review every step, step in only for the big calls, or
let it run. Today every permission request blocks for a person — the closest setting, hardcoded.
This makes it a setting. The distinction that keeps it honest: a **permission request** is the
harness's own tool gating, answerable from the options the agent itself offered; an **ask**
([RQ-0016](rq-0016.md)) is a question that needs a person's judgement. Hands-off can answer the
first kind; nothing may ever answer the second on a person's behalf.

## Acceptance criteria

- [AC-1] A project carries a supervision level, changeable at any time, shown where sessions
  start.
- [AC-2] At the closest level, every permission request blocks for a person, exactly as today.
- [AC-3] At a hands-off level, a permission request is answered with the agent's own allow
  option, and the transcript records the answer as automatic — visible, never silent.
- [AC-4] Questions that are asks always reach the person, at every level.
- [AC-5] Changing the level mid-session applies from the next request; nothing already answered
  is revisited.

# RQ-0030 — Work in motion is visible

The workspace computes whether a turn is streaming and shows it nowhere; Now rows narrate in raw
protocol vocabulary with no sense of time; and when the watcher lands, changes will arrive with
nothing marking what just moved. The owner asked for "some sort of notification or indication of
work happening" — this is that, in the house's own grammar: words first, colour never alone.

## Acceptance criteria

- [AC-1] While a turn streams, the conversation's tab says so — a word and a quiet pulse — and
  stops saying so when the turn ends.
- [AC-2] A Now row shows how long since its build last said anything, and its activity reads as
  plain words, never protocol vocabulary.
- [AC-3] A rail row whose file just changed carries a transient "changed" mark that clears when
  the row is opened or shortly after.
- [AC-4] A Now row for a worktree build says the build works in its own copy, so "where are my
  files" has an answer on screen.

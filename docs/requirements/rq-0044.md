# RQ-0044 — The activity dock

**Now dies.** Its replacement is not a better tab but the end of "activity lives in a tab you must
visit": a collapsible strip across the bottom of the center panel, present on every surface. Its
input is the whole truth — the session inventory of [RQ-0040](rq-0040.md), the build and worktree
rows of [RQ-0037](rq-0037.md), background runs, terminals — because Now's structural failure was a
single data source (worktree builds) while the default build ran in chat.
[DC-0027](../decisions/dc-0027.md) records the diagnosis and the shape.

## Acceptance criteria

- [AC-1] The dock is visible from every surface: collapsed it is a 28px strip carrying one motion
  line, the amber "N needs you" rollup, and the next-action line; expanded it is a user-resizable
  panel with sections Builds, Main chat, Background runs, and Terminals.
- [AC-2] The dock derives from the session inventory — `deriveDock(sessions, builds,
  backgroundRuns, terminals)` — not from `build:list` alone; a chat-only session with no worktree
  build still shows its activity. "NowTab moved down" fails this criterion.
- [AC-3] The needs-you rollup counts the main chat waiting on the user alongside worktree
  permission requests and blocked background runs.
- [AC-4] The next-action line carries a real button — "ST-0042 waits in review → [Review]"
  presses through to the review — with the action chosen by `nextAction()`'s priority order.
- [AC-5] The Builds section keeps Now's rows and their testids (`now-row-*`, `now-badge`) and
  adds the Resume and Review actions; the Main chat section shows the current turn's activity.
- [AC-6] One extracted `PermissionCard` renders permission answering everywhere it appears; the
  three duplicated permission renderings are gone.

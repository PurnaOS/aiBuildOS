# DC-0004 — React 19, Vite 7, Tailwind 4 and Radix for the renderer

## Context

The renderer is a dense, stateful desktop UI: trees, panes, diffs, transcripts, previews. It needs a
component model, a fast dev loop, a styling system that does not fight density, and accessible
primitives that do not dictate visual design.

## Decision

**React 19** + **Vite** + **Tailwind CSS 4** (via `@tailwindcss/vite`) + **Radix UI** primitives,
styled in-repo rather than pulled from a component library wholesale.

**Vite is pinned to 7.x.** `electron-vite@5` declares `vite: ^5.0.0 || ^6.0.0 || ^7.0.0` — Vite 8 is
outside its peer range and will break the desktop build. `@vitejs/plugin-react` is pinned to `^5.2`
for the same reason.

## Consequences

- The Vite pin is a real constraint with a real expiry: revisit when electron-vite supports Vite 8.
  It is recorded here so the next person who runs `bun update` knows why the pin exists.
- Tailwind 4's Vite plugin replaces the PostCSS pipeline; there is no `tailwind.config.js` unless a
  theme needs one.
- Radix gives behaviour and accessibility; visual design stays owned in-repo.

## Alternatives considered

- **Vite 8 + a patched electron-vite**: the predecessor project carried an electron-vite patch and it
  was a recurring maintenance cost. Pinning is cheaper than patching.
- **A full component library (MUI, Mantine)**: faster to start, harder to make dense and distinctive.

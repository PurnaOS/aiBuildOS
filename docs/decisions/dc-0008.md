# DC-0008 — CopilotKit and AG-UI for conversational and generative UI

## Context

The primary interaction surface is a conversation with an agent that streams text, tool calls,
diffs, permission prompts, and interactive components. Building that surface from scratch — streaming,
partial rendering, tool-call display, generative components — is a large amount of undifferentiated
work.

## Decision

Use **CopilotKit** for the conversational UI and **AG-UI** as the event vocabulary between the agent
layer and the renderer. ACP events from the agent ([DC-0007](dc-0007.md)) are **bridged** into AG-UI
events; the renderer consumes AG-UI only.

## Consequences

- The renderer is decoupled from ACP's wire format. Protocol changes land in the bridge, not in
  components.
- The bridge is the natural place to map agent tool calls onto generative UI components, which is what
  makes rich in-conversation UI possible at all.
- CopilotKit peers React 18/19 and Zod ≥3, both of which this project already has.
- The bridge itself is not implemented in this bootstrap; it arrives with its own requirement.

## Alternatives considered

- **A hand-rolled chat UI**: full control, and months of streaming edge cases.
- **Consuming ACP events directly in React**: couples every component to the protocol.

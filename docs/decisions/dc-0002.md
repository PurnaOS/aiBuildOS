# DC-0002 — Bun and Electron's Node are separate runtimes

## Context

[DC-0001](dc-0001.md) makes Bun the tooling baseline. Electron ships and embeds **its own Node
runtime** for the main and preload processes. Treating "we use Bun" as "everything runs on Bun" is
the single most likely way to break this project silently: code written against Bun-only APIs would
pass local checks run through Bun and then fail inside Electron, where Bun does not exist.

## Decision

Draw the boundary explicitly and enforce it.

**Bun owns:** dependency install, workspace resolution, script running (`bun run`), and the runtime
for everything under `tools/` and `scripts/`.

**Electron's bundled Node owns:** `apps/desktop/src/main` and `apps/desktop/src/preload` at runtime.
Chromium owns `apps/desktop/src/renderer`.

**Bun never executes application code.** Therefore:

- No Bun-only APIs (`Bun.file`, `Bun.spawn`, `Bun.serve`, `bun:sqlite`, `Bun.$`) anywhere in `apps/`
  or `packages/` — those packages are consumed by the Electron main process. Bun-only APIs are
  confined to `tools/` and `scripts/`.
- Main-process code is bundled by electron-vite (Rollup, node target) and executed by Electron. It is
  never run with `bun <file>`.
- Tests run on Node: `bun run test` invokes Vitest, and because `bun run` honours the bin's
  `#!/usr/bin/env node` shebang, Vitest executes on Node — matching the app runtime. Do not use
  `bun --bun run` for tests, and do not use `bun test` (Bun's own runner) in this repo.

## Consequences

- Shared packages must be plain Node-compatible TypeScript. This is a real constraint on
  `packages/knowledge-engine` (filesystem access uses `node:fs`, not `Bun.file`).
- Two runtimes must be installed in CI and on developer machines.
- The check is greppable: `grep -rn "Bun\.\|bun:" apps/ packages/` must return nothing.

## Alternatives considered

- **Bun as the app runtime too**: not possible. Electron embeds Node; that is not configurable.
- **Node for everything, drop Bun**: loses the install and script-running speed for no benefit, since
  the boundary is easy to state and easy to check.

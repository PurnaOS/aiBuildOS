# ST-0019 — Choose light, dark, or whatever the system is doing

*As someone whose editor is dark and whose desktop is not, I want to say which I want here, so that I
do not have to change the desktop to change this.*

Serves [RQ-0007](../requirements/rq-0007.md).

Three choices in Settings, beside the harnesses, because appearance belongs to the installation rather
than to whichever project happens to be open.

Set through `nativeTheme.themeSource` in the main process, before the window exists. That is what makes
the setting arrive before the first frame instead of as a flash of the wrong theme afterwards — and it
is why nothing in the renderer had to change to follow it.

## Acceptance criteria

- [AC-1] Settings offers system, light and dark, and shows which is in force.
- [AC-2] Choosing one changes the window at once.
- [AC-3] The choice is stored beside the other installation configuration and read at startup.
- [AC-4] A fresh installation follows the system, as does one whose settings file cannot be read.
- [AC-5] A choice that cannot be saved is still applied, and the failure is reported rather than
  swallowed.

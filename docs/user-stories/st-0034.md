# ST-0034 — Hands-off answers permissions, and never answers questions

*As someone who trusts the agent with the routine, I want permission requests answered for me at
the level I chose, so that supervision is my dial and not my job.*

Serves [RQ-0022](../requirements/rq-0022.md). The level lives in the project's settings, shown as
a control where sessions start; the answering happens in main where the permission flow already
is (DC-0017): at hands-off, a request is answered with the agent's own allow option and the
transcript's permission card shows it was automatic. Asks (RQ-0016) are renderer-detected message
content, untouched by any of this — they cannot be auto-answered by construction.

## Acceptance criteria

- [AC-1] The level is a per-project setting with a visible control; closest blocks everything for
  a person, as today.
- [AC-2] Hands-off answers a permission request with the agent's own allow option, marked
  automatic in the transcript.
- [AC-3] Asks always reach the person; changing the level applies from the next request.

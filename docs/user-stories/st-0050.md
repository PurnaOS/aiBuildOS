# ST-0050 — The sync header knows the branch facts

*As someone deciding whether to push or pull, I want the current branch and its ahead/behind
counts in front of me, so that sync is a fact I read, not a guess I make.*

Implements [RQ-0033](../requirements/rq-0033.md): a `project:branches` channel backed by one
`for-each-ref` verb (`%1f` separators; upstream and ahead/behind per branch), the current
branch's counts parsed free from `# branch.ab` in the existing porcelain-v2 `changes()`, and a
slim sync header atop the FilesRail git pane — `⎇ branch ▾ · ↑2 ↓0 [Push] [Pull]`. No upstream
is `null`, never zero, all the way from parse to pixels.

## Acceptance criteria

- [AC-1] The git pane's sync header names the current branch, its ahead/behind counts, and the
  Push and Pull actions.
- [AC-2] One `project:branches` call lists every local branch with upstream and ahead/behind.
- [AC-3] A branch with no upstream carries `null` counts and renders none — distinguishable from
  `↑0 ↓0`.
- [AC-4] The header's counts move when a commit, push, pull or fetch changes the facts, with no
  refresh pressed.

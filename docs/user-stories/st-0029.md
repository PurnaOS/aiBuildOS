# ST-0029 — The cards sort by what matters first

*As someone scanning a column, I want the important work at the top, so that priority is a fact
the board uses rather than a field only the editor shows.*

Fixes [BG-0005](../bugs/bg-0005.md) for [RQ-0011](../requirements/rq-0011.md)#AC-5. The record
read carries each artifact's `priority` (absent stays absent — a card without one sorts last),
and the boards hand it through to the derivation that always knew what to do with it.

## Acceptance criteria

- [AC-1] The record read carries `priority` where an artifact declares one.
- [AC-2] A column orders `p1` before `p3` whatever the IDs argue, and cards without a priority
  sort after every prioritised one.

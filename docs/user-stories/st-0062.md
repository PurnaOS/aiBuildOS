# ST-0062 — The activity dock

*As someone with work in flight, I want everything moving visible from wherever I stand, so that
I never visit a tab to learn whether anything needs me.*

The dock-core slice of [RQ-0044](../requirements/rq-0044.md), shaped by
[DC-0027](../decisions/dc-0027.md): Now dies, and `now/NowTab.tsx` becomes `dock/ActivityDock.tsx`
with `now/now.ts` becoming `dock/derive.ts`. The derivation input is the session inventory —
`deriveDock(sessions, builds, backgroundRuns, terminals)` — because Now's structural failure was a
single data source while the default build ran in chat. The permission-card consolidation is
[ST-0063](st-0063.md)'s slice of the same requirement.

## Acceptance criteria

- [AC-1] The dock renders on every surface: collapsed, a 28px strip with the motion line, the
  amber "N needs you" rollup, and a next-action button; expanded, a user-resizable panel with
  sections Builds, Main chat, Background runs, and Terminals.
- [AC-2] `deriveDock` reads the session inventory, not `build:list` alone: a chat-only session
  shows its activity, and the rollup counts the main chat waiting on the user.
- [AC-3] The Builds section keeps Now's rows and testids (`now-row-*`, `now-badge`) and adds
  Resume and Review; the next-action button follows `nextAction()`'s priority order.

# ST-0047 — The command card becomes a terminal

*As someone watching the agent run my tests, I want the command, its output as it happens, and
how it ended, so that the transcript is worth watching.*

Serves [RQ-0031](../requirements/rq-0031.md). The card learns to read what the wire already
carries: the command from the call's raw input, live chunks from the update events nothing
consumed, the outcome and duration in words, long output folded behind its count, touched files
that survive the result, honest fallbacks for unparseable results and terminal handles. The stub
streams multi-chunk execute output so every piece is testable without a model.

## Acceptance criteria

- [AC-1] The command shows from start; output streams live; the end is words and a duration.
- [AC-2] Long output folds behind "show all N lines"; unparseable results render as text; a
  terminal handle renders honestly; touched files persist.

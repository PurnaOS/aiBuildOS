# ST-0045 — A new project tells any agent how to behave

*As someone attaching their own coding agent, I want the project to already carry the house
rules where agents look for them, so that the first turn behaves like the hundredth.*

Serves [RQ-0028](../requirements/rq-0028.md). Root `AGENTS.md` in the scaffold template (the
glob pattern grows to template-root files), `CLAUDE.md` as an import line, the state discipline
written exactly as the owner bounded it, the seed action covering adopted projects without ever
overwriting, and this repository's own root dogfooding the same file.

## Acceptance criteria

- [AC-1] A created project carries both files with the decided content; an adopted one gains
  them from the seed action; an existing file is never overwritten.
- [AC-2] The state discipline in the file matches the owner's decision word for word where it
  matters: work states only, worktree hands-off, scheduling and verdicts the person's.
- [AC-3] This repository's root carries the same AGENTS.md.

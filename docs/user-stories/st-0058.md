# ST-0058 — Session visibility

*As someone glancing at the dock, I want every session to say what it is, so that a blocked
background run cannot hide.*

Implements [RQ-0040](../requirements/rq-0040.md): `session:list` rows gain `label` and
`startedAt`, and a session's kind is derived — `storyId` means build, `label` means task, neither
means chat — never stored beside the fields it derives from. The payoff case is a background run
under `closest` supervision hitting a permission ask with nobody watching its tab: the inventory
now carries enough for the dock to render and answer it.

## Acceptance criteria

- [AC-1] Every session row says what it is — build, task, or chat — from its fields alone, with
  no stored kind anywhere.
- [AC-2] A background run blocked on a `closest` permission ask is visible in the dock and
  answerable from there.

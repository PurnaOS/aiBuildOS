# ST-0008 — Validate links and body structure

*As someone maintaining the record, I want a link that points at the wrong kind of thing, a missing
acceptance criteria section, or a dependency cycle to be caught, so the traceability chains actually
hold.*

Serves [RQ-0003](../requirements/rq-0003.md) criteria AC-8 through AC-13. Loading the profile is
[ST-0006](st-0006.md); frontmatter is [ST-0007](st-0007.md).

This is the half that makes the [traceability chains](../README.md#traceability) real. `min: 1` on a
Story's `implements` and `verified_by` is *"the load-bearing part of the traceability model"*
([the Story profile](../profile/story.md)) — enforced here for the first time.

Cardinality exempts an artifact still in its type's initial state. Conventions §4 spells the
constraint as *"`min: 1` for a Story at `ready`"* while the profile stores a bare `min: 1`, and
[conventions wins by precedence](../../CLAUDE.md). Flipping to `ready` is the scheduling act; a draft
is allowed to be half-written, and a validator that forbids that makes drafting impossible.

Body rules need the artifact body, which the loader currently parses and discards.

## Acceptance criteria

- [AC-1] A relationship the artifact's type does not declare is reported at warning severity — an
  unknown field is tolerated, not rejected.
- [AC-2] A link whose target has a type the relationship does not accept is an error, naming both the
  relationship and the type it got.
- [AC-3] A target type that extends an accepted type is accepted, so `target: [WorkItem]` takes a
  Story or a Bug.
- [AC-4] A target whose type the profile does not define is accepted by name, so
  `constrains: [AR-0002]` against `target: [..., Architecture]` is not a failure.
- [AC-5] A link to an artifact that does not exist produces one finding, not two — the existing
  `link/target-exists` rule owns it and the type check stands down.
- [AC-6] `min` and `max` are enforced, and `min` is not applied while the artifact is in its type's
  initial state.
- [AC-7] A cycle in a relationship declared `cycles: forbid` is reported once, naming the path around
  it, rather than once per artifact on it.
- [AC-8] A body section the type declares `required` and the artifact lacks is an error.
- [AC-9] A section marked `items: AC` with no `[AC-n]` items, or with a number used twice, is an
  error.
- [AC-10] A link naming a criterion (`RQ-0007#AC-2`) whose artifact exists but whose criterion does
  not is an error.

## Notes

`ArtifactGraph` already stores outbound edges and derives inbound ones, and already strips the
`#AC-n` suffix when building them. Cycle detection walks it per relationship; nothing here writes a
backlink or a second graph.

# ST-0031 — An idea becomes draft requirements through an interview

*As someone with an idea and no template, I want to describe it and answer questions, so that a
backlog appears without my knowing how requirements are written.*

Serves [RQ-0017](../requirements/rq-0017.md). Three pieces, none of them new machinery: the
intake playbook (`PB-0001`) grows the interview discipline — one question per turn as a
[DC-0020](../decisions/dc-0020.md) fence, draft Requirements written per the conventions as
things are settled; the idle conversation offers "Start from an idea" as the front door; and the
backlog shows drafts as they land, which it already does at every turn's end. Abandoning is just
stopping; re-entering is pressing the button again.

## Acceptance criteria

- [AC-1] The conversation offers intake as a playbook front door; pressing it sends the intake
  instructions with whatever the user typed or pasted.
- [AC-2] The stub interview's questions arrive as cards, one per turn, and its settled drafts
  appear on the backlog at each turn's end.
- [AC-3] Stopping mid-interview keeps the drafts written so far, as drafts; pressing the door
  again starts a fresh interview against the same record.

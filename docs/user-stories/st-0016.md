# ST-0016 — The conversation looks like part of the application

*As someone using this on a dark desktop, I want the conversation to be dark like everything around
it, so that the centre of the window does not read as an embedded web page.*

Fixes [BG-0002](../bugs/bg-0002.md). Serves [RQ-0004](../requirements/rq-0004.md)#AC-1.

CopilotKit draws from its own custom properties, so the fix is to declare them in this application's
palette rather than to fight its stylesheet. That also means the conversation is not merely *a* dark
theme but *this* application's — the same neutrals as the rails, the same borders.

Following the system appearance is left to CSS. A class toggled from JavaScript would be a second
source of truth about something the browser already knows.

## Acceptance criteria

- [AC-1] The conversation's surfaces, text, borders and composer use the application's own palette.
- [AC-2] The appearance follows the system's light or dark setting, with no class or attribute
  maintained by the application to say which.
- [AC-3] The declarations survive the build, whatever order the bundler emits the stylesheets in.

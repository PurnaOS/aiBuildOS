# ST-0040 — A turn's end always lands on screen

*As someone waiting on a build, I want a failed read at the turn's end to say so instead of
freezing the picture, so that "nothing changed" always means nothing changed.*

Fixes [BG-0006](../bugs/bg-0006.md). The turn-end handlers stop swallowing: the refresh signal
fires in a `finally`, and a flip that could not be attempted or landed surfaces where problems
already surface. (RQ-0026's watcher will retire these bumps; until it lands, they must at least
never vanish.)

## Acceptance criteria

- [AC-1] A rejected read or save at turn end still refreshes the workspace.
- [AC-2] The failure is shown in words where the affected surface already shows problems.

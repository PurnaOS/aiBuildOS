# ST-0038 — Builds run side by side, and Now shows them all

*As someone with three things building, I want one glance to answer "what is moving and what
needs me", so that parallel work is calm instead of tabs.*

Serves [RQ-0021](../requirements/rq-0021.md). A pinned Now tab beside Board: one row per running
build — story, state, latest activity — with the agent's plan glyphs the Activity surface already
uses, a needs-you mark in words and count on the tab label itself, and each build's stream one
press away as a session tab. Cancelling one build cancels one session; the cap is three,
stated on the surface.

## Acceptance criteria

- [AC-1] Two stories build at once in separate worktrees; Now lists both, live.
- [AC-2] The Now tab's label carries a needs-you count whenever any build waits on a person, and
  the row answers the wait inline where the options allow.
- [AC-3] Opening a build's row shows its conversation; closing that tab stops nothing.
- [AC-4] Cancelling one build leaves the other running, and the Work board shows both cards'
  true states throughout.

# ST-0007 — Validate frontmatter against its type

*As someone writing an artifact, I want to be told when its frontmatter disagrees with its type, so
the schema in `docs/profile/` means something.*

Serves [RQ-0003](../requirements/rq-0003.md) criteria AC-2 through AC-7. Loading the profile is
[ST-0006](st-0006.md); links and body structure are [ST-0008](st-0008.md).

The severities are the design, not a detail. An artifact of a type the profile has not described is a
**warning**: `AR` is ID-reserved and deliberately unprofiled
([conventions §3](../guidelines/okf-conventions.md#3-ids-and-file-layout)), and OKF requires a reader
to tolerate unknown types. Everything the profile *does* describe is an error, because there the
schema has an opinion and the artifact contradicts it.

## Acceptance criteria

- [AC-1] An artifact whose type has no definition is reported at warning severity and still checked
  against the common frontmatter rules. It is never an error.
- [AC-2] An artifact whose type is marked `abstract` is an error — abstract types are never
  instantiated.
- [AC-3] An ID whose prefix is not the one its type declares is an error, and so is an artifact
  sitting outside the directory its type declares.
- [AC-4] A field the type declares `required` and the artifact omits is an error, reported against
  the artifact rather than against the type.
- [AC-5] A field constrained by `values:` holding something else is an error naming what was allowed.
- [AC-6] A `state` outside the type's vocabulary is an error. States are checked for membership only;
  transitions between them need history and are not in scope.
- [AC-7] An artifact with `provenance: agent` and no `generated` is an error
  ([conventions §2](../guidelines/okf-conventions.md#2-common-frontmatter)).
- [AC-8] Every finding points at the frontmatter key that caused it, by line, so the report is
  navigable.

## Notes

The four rules that already exist — `id/format`, `id/duplicate`, `index/listed`,
`link/target-exists` — keep working unchanged and keep their rule names. This story adds to the
registry; it does not renumber it.

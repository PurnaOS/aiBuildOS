# ST-0022 — Collapse the sidebar

*As someone with three panes of work on screen, I want the column of chrome out of the way, so that
the window is mostly the thing I am doing.*

Serves [RQ-0009](../requirements/rq-0009.md).

Collapsed to nothing, with a small persistent handle to bring it back — an affordance that only
existed as a keystroke would be one most people never find, and the project's own status discipline
says a signal must never be available one way only.

Remembered in the **installation's settings file**, with the pane layout moved there beside it. The
obvious home was the renderer's own storage, next to where the layout already lived — until a probe
showed that nothing there survives a restart at all ([BG-0004](../bugs/bg-0004.md)). Where someone
left the furniture is worth keeping properly, and main writes that file the moment it changes.

## Acceptance criteria

- [AC-1] A control collapses the sidebar to no width, and a handle in its place restores it.
- [AC-2] ⌘B toggles it, and the menu says so.
- [AC-3] Where it was left survives a restart, because it is written where a restart can find it.
- [AC-4] The pane widths survive a restart too, which they did not before.

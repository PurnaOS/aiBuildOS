# ST-0063 — One permission card

*As someone answering an agent, I want the same permission card wherever a permission appears, so
that answering is one learned act rather than three near-copies drifting apart.*

The consolidation slice of [RQ-0044](../requirements/rq-0044.md)#AC-6: one extracted
`dock/PermissionCard.tsx` replaces the three duplicated permission-answering renderings, and every
surface that shows a permission — dock row, session tab — renders the same component. Split from
[ST-0062](st-0062.md) so the dock's derivation and its chrome land independently.

## Acceptance criteria

- [AC-1] One `PermissionCard` component renders permission answering everywhere it appears; the
  three duplicated renderings are deleted.
- [AC-2] A permission is answerable from the dock row and from the session tab through that same
  component, and each permission accepts exactly one answer.

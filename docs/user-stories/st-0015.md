# ST-0015 — The rails follow the work as it happens

*As someone watching an agent work, I want the record and the file tree to show what it just did, so
that I do not have to reopen the project to find out whether anything happened.*

Fixes [BG-0001](../bugs/bg-0001.md). Serves [RQ-0004](../requirements/rq-0004.md)#AC-14 and #AC-15.

The moment to look is the same one the editors already use: a turn ending is when the agent has
stopped changing things. Everything the rails hold is re-read then — the record, the changed paths,
and every directory currently expanded.

The user's own writing counts as work too. Saving an artifact must refresh the rails as surely as the
agent's writing does, or the same bug returns wearing different clothes.

## Acceptance criteria

- [AC-1] When a turn ends, the record rail shows artifacts the agent created, and stops showing ones
  it deleted.
- [AC-2] When a turn ends, every expanded directory in the file tree and the Git tab are re-read.
- [AC-3] Saving an artifact refreshes the rails without waiting for an agent.
- [AC-4] A refresh keeps the rails as the user left them: what was expanded stays expanded, and the
  filter still applies.

# ST-0049 — Push, pull and fetch from the workspace

*As someone whose branches live in the app, I want to push, pull and fetch without a terminal,
so that the remote is one press away and never touched unasked.*

Implements [RQ-0032](../requirements/rq-0032.md) on the posture
[DC-0023](../decisions/dc-0023.md) settles: `git.ts` gains `fetch`, `pull` (`--ff-only`) and
`push` verbs through the existing argv-only chokepoint — plain `git()`, not the read guard — and
`project:fetch/pull/push` channels carry them. `toGitError` grows regex-mapped `git_auth` and
`no_remote` codes; a push with no upstream retries as `push -u origin <branch>`. The watcher
already sees `.git/refs`, so no refresh plumbing is added.

## Acceptance criteria

- [AC-1] Fetch, pull and push each run only from their channel — nothing contacts a remote on a
  timer or a watcher event.
- [AC-2] A diverged pull fails with git's own stderr preserved; a push with no upstream publishes
  the branch via the `-u origin <branch>` retry.
- [AC-3] Authentication and missing-remote failures come back as `git_auth` and `no_remote`
  codes with the stderr alongside.
- [AC-4] A fetch or pull that moves refs reaches the git surfaces through the existing watcher,
  with nothing further pressed.

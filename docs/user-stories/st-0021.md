# ST-0021 — Stop asking me to save

*As someone editing a file while an agent works in the same repository, I want my typing kept without
my having to think about it, and ⌘S to do what it does everywhere else.*

Serves [RQ-0008](../requirements/rq-0008.md).

One hook, used by every editor: the debounce, the suppressions and the shortcut are the same rules
wherever the editing happens, and three copies of them would drift into three behaviours.

The suppressions are the interesting part. A write is held back while a turn is streaming and while
the conflict bar is up, because in both cases something else has a claim on the file and a timer is
the wrong thing to settle it with. When the turn ends the existing reconciliation runs first, and only
then does what was typed get written.

The menu is set rather than inherited, so it has to carry the roles the platform's own menu provided —
adding ⌘S at the cost of ⌘C would be a poor trade.

## Acceptance criteria

- [AC-1] Every editor writes shortly after typing stops, and coalesces a burst into one write.
- [AC-2] ⌘S writes immediately, from the menu or the keyboard.
- [AC-3] No write happens while a turn is streaming, or while the conflict bar is up.
- [AC-4] What was typed during a turn is written once the turn has ended and been reconciled.
- [AC-5] The Save button is gone, and the tab's marker means a write is *waiting on something* rather
  than merely not written yet — which is the same condition under which closing still asks.
- [AC-6] Copy, paste, undo, select-all, close and quit still work.

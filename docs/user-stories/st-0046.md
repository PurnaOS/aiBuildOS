# ST-0046 — The rail folds, counts, and filters from the top

*As someone with seventy artifacts and counting, I want groups that fold and say how much they
hold, so that the rail is a map again instead of a scroll.*

Serves [RQ-0029](../requirements/rq-0029.md): group headers become buttons with chevron and
count, folding survives refresh; the filter moves to the top with a clear press and a match
count; the chrome findings ride along — the styled discard dialog replacing `window.confirm`,
distinct icons per tab kind, one shared quiet loading treatment.

## Acceptance criteria

- [AC-1] Groups fold and unfold from their headers, counts always visible, folding surviving a
  refresh, filter reaching into folded groups.
- [AC-2] The filter is at the top, counts its matches, clears in one press.
- [AC-3] The discard prompt is the application's own dialog in both appearances; every special
  tab kind carries its own icon; loading is one treatment.

# ST-0056 — A real shell

*As someone running the project, I want a real terminal inside the workspace, so that a dev
server or a quick command never means leaving the app.*

Implements [RQ-0038](../requirements/rq-0038.md) on the mechanism
[DC-0026](../decisions/dc-0026.md) settles: `main/terminals.ts` spawns PTYs through an injected
pty-factory (never a top-level node-pty import), the `terminal:*` channels and events carry the
bytes, and the dock's Terminals section renders the rows and the xterm view. The cwd is resolved
main-side from the project registry; the user's own typed commands run unsupervised.

## Acceptance criteria

- [AC-1] A terminal opened from the dock runs the user's own shell in the project's directory,
  with its output live in the dock's resizable panel.
- [AC-2] Several terminals coexist as rows in the dock's Terminals section, and the registry
  lists them all.
- [AC-3] Closing the project or quitting the app leaves no shell process running.

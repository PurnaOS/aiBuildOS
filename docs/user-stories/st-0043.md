# ST-0043 — The workspace watches its project

*As someone whose agent, terminal and editor all write the same files, I want the workspace to
notice within a blink, so that the screens are the live look they claim to be.*

Serves [RQ-0026](../requirements/rq-0026.md) as [DC-0022](../decisions/dc-0022.md) decides it:
a chokidar watcher per open project in main, one debounced `project:changed` event, the
renderer's one `bump()` on the other end, the turn-end bumps retired, the record read cached by
generation and invalidated by the watcher itself.

## Acceptance criteria

- [AC-1] External writes, mid-turn agent writes and terminal commits each appear within the
  debounce, proven against the running application.
- [AC-2] The turn-end refresh paths no longer bump; a single change produces a single refresh.
- [AC-3] The record read is served from cache between changes and re-parsed after one.
- [AC-4] Open, close, switch, quit: watchers start and stop with the project, verified by
  behaviour, not by inspection.

# ST-0009 — Stream a live agent session into the workspace

*As someone driving a coding agent, I want to see it work as it works — its words, its thinking, the
tools it runs and the changes it makes — so I can tell what is happening while it is happening.*

Serves [RQ-0004](../requirements/rq-0004.md) criteria AC-3 through AC-8, AC-11, AC-17 and AC-18. What
the agent asks and what it can be told is [ST-0010](st-0010.md).

This is the foundational slice and it is three things that do not exist yet: a one-way event channel
across the IPC boundary, an ACP session held open across prompts instead of the one-shot probe, and
the ACP-to-AG-UI bridge that [DC-0017](../decisions/dc-0017.md) places in the main process.

The probe already drains streaming updates and throws all but the message text away. This keeps them.

## Acceptance criteria

- [AC-1] The IPC contract carries events as well as channels. An event has a name and a Zod payload
  schema, is validated on the way out and on the way in, and travels main to renderer only.
- [AC-2] The event router is testable with no Electron runtime, the same way the request router is —
  it takes a structural sender rather than Electron's own type.
- [AC-3] Subscribing returns a way to unsubscribe, and a payload that does not match its schema is
  reported rather than delivered.
- [AC-4] A session spawns the harness once, completes the handshake, opens a session and stays open.
  A second prompt reuses it.
- [AC-5] Every session update the agent sends is bridged and emitted: message text, reasoning, tool
  calls and their updates, plans, usage and session info.
- [AC-6] Message chunks that share an identifier are one message; a new identifier starts another.
- [AC-7] A tool call's content and locations are replaced when the agent updates them, not appended
  to, because that is what the protocol says they mean.
- [AC-8] Cancelling sends the protocol's cancel notification, keeps accepting updates until the turn
  resolves, and reports the turn as cancelled.
- [AC-9] Closing a project, or quitting, terminates the agent and everything it spawned.
- [AC-10] Every failure — the command not found, an exit before the handshake, a protocol error, a
  session that was never started — is reported as a named outcome rather than as a thrown error.
- [AC-11] The renderer never imports the agent protocol. It receives AG-UI events and nothing else.

## Notes

The scripted stub agent emits exactly one of the protocol's thirteen update kinds today. It grows
tool calls, diffs, plans and a cancel path here, because otherwise none of this is testable without a
live model ([DC-0013](../decisions/dc-0013.md)).

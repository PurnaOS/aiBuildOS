# ST-0018 — The editors are dark when the window is

*As someone reading code in a dark window, I want the editor to be dark too, so that the thing I spend
the most time looking at is the one thing I can actually read.*

Fixes [BG-0003](../bugs/bg-0003.md). Serves [RQ-0004](../requirements/rq-0004.md)#AC-1.

CodeMirror is themed in JavaScript rather than in CSS, so this is the one surface a media query cannot
reach on its own. The renderer therefore *observes* the media query and hands the answer down — which
is still the browser deciding, not a second source of truth about which appearance is in force.

## Acceptance criteria

- [AC-1] Every editor surface uses the dark theme when the window is dark, and the light one when it
  is not.
- [AC-2] The editor's ground is the application's own, not a theme's idea of dark.
- [AC-3] Changing the system appearance changes the editors without reopening anything.

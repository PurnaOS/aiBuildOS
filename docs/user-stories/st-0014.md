# ST-0014 — Author an artifact through its own profile

*As someone about to ask for a feature, I want to write the requirement here, as a requirement rather
than as a text file, so that the artifact I author by hand and the one I author in the app are the
same bytes.*

Serves [RQ-0005](../requirements/rq-0005.md) criteria AC-5 to AC-10.

This is the first thing in the repository that **writes** to `docs/`, and it is the write path
[DC-0009](../decisions/dc-0009.md) deferred. The property that matters is not convenience: `docs/` is
committed, so a writer that reformats frontmatter it never touched destroys the diff, and the diff is
how a person reviews what an agent did.

Nothing about the shape is hardcoded. The states offered are the vocabulary the type declares, and the
artifacts offered for a link are the ones its target types allow — read from the profile
[RQ-0003](../requirements/rq-0003.md) taught the engine to resolve. A relationship the file has never
carried can still be added, because the profile is what vouches for it; a key nobody vouched for is
still refused rather than invented.

## Acceptance criteria

- [AC-1] An artifact opens as its fields, its links, its body and its acceptance criteria, not as raw
  text.
- [AC-2] The states offered are that type's own vocabulary.
- [AC-3] The artifacts offered for a relationship are only those its declared targets allow.
- [AC-4] Criterion numbers are append-only: removing one retires its number.
- [AC-5] Saving leaves every field, comment and formatting choice that was not edited byte-identical.
- [AC-6] Saving keeps the artifact's row in its directory index in step with it.
- [AC-7] A validation finding is shown against the field that caused it, and a value the type does
  not declare is still shown as the artifact's own.
- [AC-8] An artifact the agent rewrites while it is open is reloaded when nothing here was edited,
  and keeps both versions when something was.

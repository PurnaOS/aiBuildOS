# ST-0020 — Make a file where you are looking

*As someone who has just found the directory a file belongs in, I want to make it right there, so that
I do not have to describe from the root of the project a place I am already pointing at.*

Serves [RQ-0006](../requirements/rq-0006.md)#AC-9.

A **native** menu, built and shown by the main process. The alternative — a floating div on a
`contextmenu` event — has to reimplement dismissal, keyboard navigation and platform appearance, and
gets all three slightly wrong. Electron already has the real thing.

Right-clicking a folder offers to make a file in it; right-clicking a file offers to make one beside
it, which is the same question asked from a different row. The existing create path does the work —
the menu only decides which directory it starts in.

## Acceptance criteria

- [AC-1] Right-clicking a row in the file tree opens the platform's own menu.
- [AC-2] Choosing to make a file starts the existing create flow, with the directory already filled
  in: a folder's own path, or the folder a file sits in.
- [AC-3] Dismissing the menu does nothing at all.
- [AC-4] What is created appears in the tree and opens for editing, exactly as it does from the rail.

# EP-0002 — Projects

The subject of the work. [EP-0001](ep-0001.md) gave the product an agent to drive; this gives it
something to drive the agent *at*. Everything after it — sessions, worktrees, previews, the record —
is scoped to a project, so it has to exist before any of them.

Implements [RQ-0002](../requirements/rq-0002.md).

## Scope

### In scope

- The project registry: what is stored about a project, and where.
- Creating a project — the native location picker, the directory, `git init`, an initial commit, and
  a seeded OKF bundle.
- Adopting an existing local directory, initialising it as a repository if it is not one.
- The launch page: every registered project, its branch and working-tree state, opened in one click.
- The project workspace: branch, working-tree counts, recent commits, and the OKF record summary.
- Forgetting a project without touching its files, including one whose directory has gone.

### Out of scope

- Pointing harness spawns at the open project. `harness:test` keeps using the harness's own working
  directory ([RQ-0001](../requirements/rq-0001.md)#AC-1); making the open project the default is its
  own criterion on its own requirement.
- Cloning from a remote. "Existing repository" means a directory already on this machine.
- Worktrees, branch switching, staging and committing from the UI. The isolation model in
  [DC-0010](../decisions/dc-0010.md) is a later requirement.
- Seeding an OKF bundle into a project that was adopted without one.
- More than one project open at a time.

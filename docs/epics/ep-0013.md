# EP-0013 — The workspace flows

Second real use put the diagnosis in the owner's own words: the center panel is too busy, has no
flow, and demands too much tab switching — and the Now tab's purpose was a mystery. A UX inventory
traced each complaint to structure, not polish: Now only ever showed worktree builds while the
default build ran in chat, so it sat empty; playbooks, commands, session mode and supervision each
claimed their own strip of chrome; and the board tabs nested a second tab strip inside the first.
This epic is the redesign those findings drove: three surfaces, one agent popover, playbooks in
the composer, and a persistent activity dock in Now's place ([DC-0027](../decisions/dc-0027.md)).

## Scope

### In scope

- Every affordance does something: rail links open, dialogs are the app's own, labels say what a
  press does ([RQ-0041](../requirements/rq-0041.md)).
- One popover for everything about the agent — session mode, harness options, supervision
  ([RQ-0042](../requirements/rq-0042.md)).
- Playbooks move into the composer and the empty transcript; the strip and the COMMANDS chip die
  ([RQ-0043](../requirements/rq-0043.md)).
- The activity dock: Now's replacement, derived from the session inventory, visible from every
  surface ([RQ-0044](../requirements/rq-0044.md)).
- Three pinned surfaces — Chat, Plan, Work — with no nested tab strips, and the Build split
  button's primary flipped to the worktree build ([RQ-0045](../requirements/rq-0045.md)).

### Out of scope

- **The backends the new chrome fronts** — remote sync, sprints, resume and worktree data belong
  to EP-0011; terminals and background runs to EP-0012. This epic gives them homes, not
  behaviour.
- **Spec migration beyond renaming homes** — testids keep their names on their new homes;
  journey and board specs are rewritten once, deliberately, when the surfaces land.
- **Document tabs** — files, sessions, plans, reviews and diffs keep their preview-tab semantics
  untouched.

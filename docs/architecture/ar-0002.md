# AR-0002 — Monorepo layout and package boundaries

Decided by [DC-0001](../decisions/dc-0001.md) (Bun workspaces),
[DC-0004](../decisions/dc-0004.md) (UI stack), [DC-0005](../decisions/dc-0005.md) (state),
[DC-0009](../decisions/dc-0009.md) (knowledge engine), [DC-0013](../decisions/dc-0013.md) (testing),
[DC-0015](../decisions/dc-0015.md) (the record). Runtime placement is [AR-0001](ar-0001.md).

## Layout

```
aiBuildOS/
├── docs/                     the OKF bundle — the system of record
├── apps/
│   └── desktop/              @aibuildos/desktop — the only application
│       ├── src/main/         Electron main: window, IPC binding
│       ├── src/preload/      contextBridge surface
│       ├── src/renderer/     React 19 + Tailwind + Zustand
│       └── e2e/              Playwright, drives the built app
├── packages/
│   ├── shared/               domain types crossing every boundary; zero dependencies
│   ├── ipc/                  Zod channel contract + typed router
│   ├── knowledge-engine/     OKF parse → validate → graph
│   └── acp/                  agent descriptors and the spawn boundary
└── tools/
    ├── okf/                  the `docs:check` validator CLI (runs on Bun)
    └── stub-acp-agent/       scripted stdio agent for tests
```

## Dependency direction

```
apps/desktop ──▶ ipc ──▶ shared
      │           ▲         ▲
      ├──▶ knowledge-engine─┤
      └──▶ acp ─────────────┘
```

`shared` depends on nothing. Nothing depends on `apps/desktop`. There are no cycles, and
`packages/*` never imports from `apps/*`.

## Conventions

- **Libraries do not build.** Every package points `main`, `types`, and `exports` at `./src/index.ts`
  and is consumed as TypeScript across the workspace. Only `apps/desktop` has a build step.
- Cross-package dependencies use `workspace:*`.
- Tests are colocated as `*.test.ts` beside the source they cover — one placement, everywhere.
- A package with no implementation yet ships `package.json` + `README.md` naming what will populate it.
  It never ships invented source.
- Per-package scripts are `typecheck` (`tsc --noEmit`) and `test` (`vitest run`).

## Why these four packages

Each is a **boundary** the product must not blur, not a layer for its own sake:

| Package | The boundary it owns |
| --- | --- |
| `shared` | the vocabulary every process agrees on |
| `ipc` | renderer ↔ main — testable without Electron because it takes structural interfaces |
| `knowledge-engine` | the OKF bundle ↔ everything else; the only code that parses `docs/` |
| `acp` | the product ↔ external agent processes; the only door to AI |

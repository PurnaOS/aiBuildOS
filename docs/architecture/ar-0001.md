## Three runtimes, and which is which

```
┌──────────────────────────────── Electron ─────────────────────────────────┐
│                                                                            │
│  ┌─ main process ──────────── Electron's bundled Node ──────────────────┐  │
│  │  window + lifecycle · IPC router · knowledge engine · ACP client     │  │
│  │  git CLI (argv) · safeStorage · execa dev servers                    │  │
│  └───────────────────────────────┬──────────────────────────────────────┘  │
│                                  │ typed IPC (Zod-validated)               │
│  ┌─ preload ── Electron's Node, isolated ──┴───────────────────────────┐   │
│  │  contextBridge: exposes the typed client, nothing else              │   │
│  └───────────────────────────────┬──────────────────────────────────────┘  │
│                                  │ contextBridge                           │
│  ┌─ renderer ─────────────────── Chromium ─┴───────────────────────────┐   │
│  │  React 19 · Zustand (UI state only) · CopilotKit / AG-UI            │   │
│  └──────────────────────────────────────────────────────────────────────┘  │
│                                                                            │
│  ┌─ WebContentsView ── separate Chromium web contents ─────────────────┐   │
│  │  the live preview of the user's project — no host access            │   │
│  └──────────────────────────────────────────────────────────────────────┘  │
└────────────────────────────────────────────────────────────────────────────┘
        │ stdio (JSON-RPC / ACP)              │ argv                │ execa
        ▼                                     ▼                     ▼
   agent processes                       system git            dev servers
   (Claude Code, Codex CLI, pi)          (+ worktrees)

┌─ Bun ─────────────────────────────────────────────────────────────────────┐
│  install · workspace resolution · `bun run` · tools/ and scripts/          │
│  NEVER executes application code                                          │
└────────────────────────────────────────────────────────────────────────────┘
```

## The boundary rule

**Bun is the tooling baseline. Electron's bundled Node is the application runtime.** They are
different runtimes with different globals, and the failure mode is silent: Bun-only code passes a
check run under Bun and then throws inside Electron, where Bun does not exist.

| Concern | Runtime | Where |
| --- | --- | --- |
| `bun install`, workspace linking, `bun run` | **Bun** | repo root |
| repo tooling and scripts | **Bun** | `tools/`, `scripts/` |
| Electron main process | **Electron's Node** | `apps/desktop/src/main` |
| preload | **Electron's Node** (isolated context) | `apps/desktop/src/preload` |
| renderer | **Chromium** | `apps/desktop/src/renderer` |
| shared packages | **Electron's Node** (they are imported by main) | `packages/*` |
| unit and component tests | **Node** (via Vitest's `#!/usr/bin/env node` bin) | everywhere |
| e2e tests | **Electron**, launched by Playwright | `apps/desktop/e2e` |

Consequences that are easy to get wrong:

1. **No Bun-only APIs in `apps/` or `packages/`.** `Bun.file`, `Bun.spawn`, `Bun.serve`, `Bun.$`,
   `bun:sqlite` are confined to `tools/` and `scripts/`. Use `node:fs`, `node:child_process`, `execa`.
   Checked with `grep -rn "Bun\.\|bun:" apps/ packages/`.
2. **Main-process code is bundled, not interpreted.** electron-vite builds it (Rollup, node target)
   and Electron executes the bundle. It is never run with `bun <file>`.
3. **`bun run test` runs Vitest on Node**, because `bun run` honours the bin's shebang. Do not use
   `bun --bun run` for tests. `bun test` (Bun's own runner) is not used in this repository.
4. **Both runtimes are required** on developer machines and in CI.

## Privilege boundaries

Everything privileged lives in the main process. The renderer has no Node integration and reaches
capability only through the typed IPC surface, which validates both directions with Zod.

- **Agents** are child processes over stdio. ACP is the only door to AI — no component holds a model
  API client.
- **Secrets** never leave the main process and are never written to `docs/` or to any tracked file.
- **Git** is the system binary invoked with argv, never a shell string.
- **Previews** run in a separate `WebContentsView` with no access to the host renderer.

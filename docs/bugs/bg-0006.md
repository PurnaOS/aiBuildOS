# BG-0006 — A turn's end can change nothing on screen

The turn-end handlers end in `.catch(() => undefined)`: one rejected read — a record mid-write, a
transient IPC failure — and the story's flip *and* the revision bump silently vanish for that
turn. The rails keep yesterday's truth, the story keeps `building`, and nothing anywhere says why.
This is the sanctioned Build path failing, not only the conversational gap: "even after a task is
implemented, its status is not changing."

## Reproduction

1. Build a story and arrange for one read at turn end to reject (an artifact briefly unreadable
   is enough).
2. Let the turn end. Expected: the failure surfaces and the workspace still refreshes. Observed:
   no flip, no refresh, no message.

# BG-0005 — The boards promise priority order and sort by ID

RQ-0011#AC-5 says a column orders by priority, then ID. The derivation does — and the record read
never carried `priority`, so every live card sorted by ID alone. The unit test passed on fixtures
that supplied what the channel never did: a green test in front of a claim the running
application did not keep.

Found in the wave-one acceptance review, which is the kind of reading that exists to catch
exactly this.

## Reproduction

1. Give two requirements the same state, the lower ID `priority: p3`, the higher `p1`.
2. Open the Backlog board. Expected: the `p1` card first. Observed: the lower ID first.

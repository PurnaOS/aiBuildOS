# BG-0007 — A build finishing after a project switch flips the wrong project's story

Build sessions outlive a project switch — only the main conversation closes with its project —
but the `building → review` flip runs in the renderer's Now tab, which saves against whichever
project is open. Switch from project A to project B while A's build runs: when it finishes, B's
same-numbered story is flipped instead. Sit on the launch page and no flip happens at all. The
flip belongs in main, which owns the session and knows its project, window or no window.

## Reproduction

1. Start a worktree build in project A on a slow story; switch to project B whose story carries
   the same ID; let the build finish. Expected: A's story at review. Observed: B's story flipped.
2. Same build, but close to the launch page instead. Expected: A's story at review on next open.
   Observed: still `building`.

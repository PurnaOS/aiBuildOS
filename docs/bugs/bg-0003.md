# BG-0003 — The code editors are white, and near-unreadable, in the dark appearance

Every CodeMirror surface — the file editor and both markdown panels of the artifact editor — draws on
white in a dark window, and its default syntax colours are pale enough on that ground that the text is
barely legible. It is the same defect [BG-0002](bg-0002.md) fixed for the conversation, in the one
place a person is actually reading and typing.

CodeMirror is themed in **JavaScript**, not in CSS: a theme is an extension, so no media query reaches
it. Nothing was passed, so it used its light default regardless of what the window around it was doing.

[RQ-0004](../requirements/rq-0004.md)#AC-1 puts these editors in one workspace, and
[RQ-0005](../requirements/rq-0005.md) is the requirement that a person edits here rather than
somewhere else — which they cannot reasonably do against text they can hardly see.

## Reproduction

1. Set the operating system to dark appearance.
2. Open a project and open any file from the files rail.
3. The editor is a white rectangle; its text is pale grey on white.
4. Open an artifact. Its body and trailing-section editors are the same.

# BG-0004 — Nothing the renderer remembers survives a restart

[RQ-0004](../requirements/rq-0004.md)#AC-1 says the side panels' sizes survive a restart. They do not.
The layout is written to the renderer's `localStorage`, and on the next launch it is gone.

Found while testing something else: a probe wrote a key, quit, relaunched into the **same** `userData`
directory, and read `null` back. So this is not a fresh profile per launch — it is that Chromium's
local storage is flushed on its own schedule, and an exit that does not wait for it loses whatever had
not been written.

The criterion has been in the bundle since the workspace shipped, verified by a case that only ever
checked the layout was remembered *within* a run. It is a clean illustration of the difference between
exercising a mechanism and asserting a property: reading back what you just wrote proves nothing about
a restart.

## Reproduction

1. Open a project and resize the record rail.
2. Quit the application and start it again.
3. The rail is back at its default width.

# BG-0002 — The conversation is light while the rest of the workspace is dark

The centre pane renders on white with dark text while the rails, the tab strip and the editors follow
the system appearance. On a dark desktop the conversation is a lit rectangle in the middle of the
application.

[RQ-0004](../requirements/rq-0004.md)#AC-1 puts the conversation in the centre of one workspace. Two
appearances in one window is not one workspace — it reads as an embedded page, which is precisely what
[DC-0017](../decisions/dc-0017.md) went to some trouble to avoid it being.

The cause is that CopilotKit's stylesheet keys its dark theme off `.dark`, `[data-theme="dark"]` or an
inline `color-scheme` on the document — none of which this application sets, because its own dark mode
comes from Tailwind's `prefers-color-scheme` variant. So the library never learns that the application
is dark, and falls back to its light defaults.

## Reproduction

1. Set the operating system to dark appearance.
2. Open a project and start a session.
3. The rails and the tab strip are dark; the conversation, its composer and its footer are white.

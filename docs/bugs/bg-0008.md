# BG-0008 — A build session's transcript shows no tool calls

The session tab listens for a `CUSTOM` event named `acp.tool_call` that the bridge defines and
has never once emitted — the branch is dead, so a build's stream shows text chunks and nothing
the agent actually did. The tool calls are on the wire the whole time, as the standard
`TOOL_CALL_*` events every other surface uses.

## Reproduction

1. Open a running build's stream from Now while its agent runs a tool.
2. Expected: the tool call in the transcript. Observed: only text, ever.

# TC-0124 — Invoking a command sends the harness's text and reads like a command

Verifies [RQ-0051](../requirements/rq-0051.md) AC-2: the wire carries exactly what the harness
expects, and the transcript renders a command card, not prose.

## Steps

1. Run `bun run test:e2e` filtered to the controls spec (build first). The commands spec lives
   here because `--mode=controls` is the only stub mode that advertises commands at all — the
   echo mode advertises none, so there is nothing to invoke there.
2. Invoke an advertised command. Expect the echoed prompt to prove the exact `/name` text
   crossed the wire — nothing typed into the composer, nothing else sent — and the transcript to
   render the invocation as RQ-0031's command card rather than an ordinary user message.

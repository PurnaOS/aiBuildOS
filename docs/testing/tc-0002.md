# TC-0002 — ACP probe completes a round trip against the stub agent

Verifies [RQ-0001](../requirements/rq-0001.md) AC-5 and AC-6. The stub agent
(`tools/stub-acp-agent`) is a real JSON-RPC stdio binary, so the spawn path and the wire handling are
genuinely exercised ([DC-0013](../decisions/dc-0013.md)). No live model is called.

## Steps

1. Probe a harness whose command spawns the stub agent.
2. Expect `ok: true`.
3. Expect the negotiated protocol version to be the SDK's `PROTOCOL_VERSION`.
4. Expect the agent identity the stub advertises — name and version — to be reported.
5. Expect a non-empty session ID.
6. Expect the reply text the stub streamed as an `agent_message_chunk`.
7. Expect the stop reason `end_turn`.
8. Expect the child process to no longer be running once the probe resolves.

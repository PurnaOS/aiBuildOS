# TC-0014 — The event channel validates both ends, delivers to subscribers and unsubscribes

Verifies [RQ-0004](../requirements/rq-0004.md) AC-3 and AC-18. Runs on Node under Vitest against an
in-memory fake, with no Electron — the same property that makes the request router testable, and the
reason the emitter takes a structural sender rather than Electron's `WebContents`.

## Steps

1. Create an emitter over a fake sender and a client over a fake receiver.
2. Emit an event whose payload matches its schema. Expect the subscriber to receive it, parsed.
3. Emit a payload that does not match. Expect the emitter to report it and expect nothing to be sent —
   an invalid event must not reach the renderer at all.
4. Deliver a payload to the client that does not match its schema. Expect a contract error naming the
   event, not a silent delivery.
5. Subscribe twice to the same event. Expect both subscribers to receive it.
6. Unsubscribe one. Expect the other to keep receiving and the unsubscribed one to stop.
7. Expect an unknown event name to be ignored rather than to throw.

# TC-0026 — An artifact is authored as its own shape, from the profile

Verifies [RQ-0005](../requirements/rq-0005.md) AC-3 to AC-10, for artifacts. Playwright against the
built application, on a project scaffolded with the OKF template and three artifacts.

What this proves that [TC-0024](tc-0024.md) cannot is that the shape in front of a person comes from
the profile rather than from anything the application believes: a state vocabulary nobody hardcoded,
and a link picker that offers a TestCase for `verified_by` and a Requirement for `depends_on` because
that is what the type declares — not because the editor was told which is which.

## Steps

1. Open a requirement from the record rail. Expect its fields, links and criteria, not raw text.
2. Expect the state options to be the Requirement vocabulary exactly.
3. Expect `verified_by` to offer the test case and not the neighbouring requirement, and `depends_on`
   the reverse.
4. Change the state, add a `verified_by` link the file has never carried, delete AC-1 and add one.
5. Save. Expect the file to carry the new state and link, and to keep its comment, its quoted title,
   its inline sequences and its untouched link byte for byte.
6. Expect AC-2 to still be AC-2 and the new criterion to be AC-3, with AC-1's number retired.
7. Expect the requirements index row to now read `ready`.
8. Change only the state of an untouched requirement. Expect the file identical but for that one
   value — the prose, the wrapping and the comment all as they were.
9. Add a sentence to the prose. Expect it written, and the criteria below it untouched.
10. Open a requirement whose state is not in its type's vocabulary. Expect the finding to be reported
    beside the state field, not in a list elsewhere — and the state control to show that value rather
    than the first one the vocabulary happens to declare.
11. Delete every criterion and add one. Expect the new one to append above the numbers that were
    retired, not to reuse them.
12. Have the agent rewrite an artifact that is open and untouched. Expect the editor to take it.
13. Have the agent rewrite an artifact that is open with unsaved edits. Expect both kept, the
    difference shown, and the choice honoured.

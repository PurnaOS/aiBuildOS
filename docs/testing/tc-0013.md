# TC-0013 — Body rules check required sections, acceptance criteria and criterion links

Verifies [RQ-0003](../requirements/rq-0003.md) AC-12 and AC-13, covering
[ST-0008](../user-stories/st-0008.md) AC-8 through AC-10. Runs on Node under Vitest.

These are the first rules to read an artifact's body rather than its frontmatter, so the loader
carrying the body through is part of what is under test.

## Steps

1. Validate an artifact missing a section its type declares `required`. Expect an error naming the
   section.
2. Validate one that has the section under a different heading level, and expect it not to count — a
   required section is a second-level heading.
3. Validate an artifact whose `items: AC` section contains no `[AC-n]` items. Expect an error.
4. Repeat with the same criterion number used twice. Expect an error naming the duplicate.
5. Repeat with criteria numbered non-contiguously — `AC-1`, `AC-3`, `AC-4`, as retiring `AC-2` would
   leave them. Expect no finding; numbers are append-only, not dense.
6. Link to a criterion that exists (`RQ-0007#AC-2` where `RQ-0007` declares `AC-2`). Expect no
   finding.
7. Link to a criterion number the target artifact does not declare. Expect an error naming both.
8. Link to a criterion on an artifact that does not exist at all. Expect only the pre-existing
   `link/target-exists` finding.
9. Validate an artifact whose type declares no `body.sections` and expect no body findings.

# TC-0048 — The build walk and the send-back are record edits, and survive a restart

Verifies [RQ-0015](../requirements/rq-0015.md) AC-1, AC-4 and AC-6 as logic: the state walk a
build performs and the edit a verdict performs, each expressed as guarded record edits.

## Steps

1. Start a build on a ready story. Expect the walk `ready → queued → building` as guarded edits,
   and the composed build prompt carrying the story and its requirement.
2. Accept from review. Expect one flip to `accepted`. Send back instead. Expect `building`, the
   note appended to the story's body, and the note in the prompt sent onward.
3. Re-derive from the files alone at each stage. Expect the same picture — nothing lives outside

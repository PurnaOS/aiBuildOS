# TC-0102 — A playbook runs in the background while the chat keeps talking

Verifies [RQ-0039](../requirements/rq-0039.md) AC-1 and AC-4 through the running application,
against the stub agent scripted to write an artifact mid-run.

## Steps

1. Start a playbook as a background run with a label. Expect the main chat to stay interactive
   for the whole run: send a prompt and receive its reply while the run is still going.
2. Let the run write its artifact. Expect the artifact to appear in the workspace via the
   watcher — no turn-end wiring exists for background sessions to fire.

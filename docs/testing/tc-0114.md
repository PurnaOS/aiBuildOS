# TC-0114 — The same card answers from the dock and the tab

Verifies [RQ-0044](../requirements/rq-0044.md) AC-6 through the running application, against the
stub agent raising real permission requests: wherever a permission appears, it is the one
`PermissionCard` — answerable in place, and never a third rendering drifting on its own.

## Steps

1. Drive the stub to a permission request in a worktree build. Expect the dock's build row to
   carry the card; answer it there and expect the build to continue with that answer.
2. Drive a second request and answer it from the session tab instead. Expect the same card —
   same markup, same testids — and the same continuation.
3. While a request is pending, expect exactly one rendering of it per surface and no leftover of
   the three duplicated renderings anywhere in the DOM.

# TC-0039 — The editor offers only the legal next states, and the record follows

Verifies [RQ-0010](../requirements/rq-0010.md) AC-1, AC-5 and AC-6 through the running
application.

## Steps

1. Open an artifact. Expect its state control to offer exactly the current state plus the profile's
   legal next states from it.
2. Make a legal flip. Expect the file's frontmatter and its index row changed in the same save.
3. Ask the save path directly for a state change along a pair the type does not declare, and for a
   body edit that reuses an `[AC-n]` number — the control itself can never produce either. Expect
   both refused, in words naming what was refused, and the file unchanged.
4. Open an artifact whose state is not in its type's vocabulary. Expect it displayed as found, not
   corrected, with only retirement offered.

# TC-0104 — A blocked background run is found and answered from the dock

Verifies [RQ-0040](../requirements/rq-0040.md) AC-3 through the running application: the case
that makes `label` and `startedAt` earn their place — a background run hits a permission ask
with nobody watching its tab, and the dock is enough to find it and free it.

## Steps

1. Start a background run under `closest` supervision, with the stub agent scripted to request
   a permission mid-run. Expect the run to block on the ask.
2. Without opening the run's tab, expect the dock to show the blocked ask on the run's row —
   the `session:list` data alone made it discoverable.
3. Answer the ask from the dock. Expect the run to resume and finish.

# TC-0067 — A worktree build leaves the workspace free, and lands on accept

Verifies [RQ-0020](../requirements/rq-0020.md) AC-1, AC-2, AC-4 and AC-6 through the running
application, against the stub's `file-writer` spawned with a worktree cwd.

## Steps

1. Build a ready story in a worktree. Expect the stub's file landing in the worktree and not in
   the main tree, and the main workspace's editors still usable mid-build.
2. When the build reaches review, accept. Expect the change merged into main, the worktree and
   branch gone, and the story accepted.
3. Restart with a build interrupted. Expect the surviving worktree listed and a fresh session
   able to pick the story up.

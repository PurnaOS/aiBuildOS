# TC-0110 — Playbooks start from the composer, and only from there

Verifies [RQ-0043](../requirements/rq-0043.md) end to end against the stub agent: the permanent
chrome is gone, and every way a playbook used to start still starts — from the `+` menu, from a
starter card, and through intake's idea prompt.

## Steps

1. Open a project with a transcript. Expect no playbook strip and no COMMANDS chip anywhere —
   the only playbook affordance is the composer's `+` menu.
2. Run a playbook from the `+` menu. Expect the composed prompt to reach the stub exactly as the
   strip once sent it.
3. Open a project with an empty transcript. Expect the playbooks as centred starter cards;
   picking one starts that playbook.
4. Choose intake. Expect the idea prompt to open before anything is composed, as it did before.

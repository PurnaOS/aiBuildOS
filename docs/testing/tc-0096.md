# TC-0096 — An orphaned build resumes after a relaunch

Verifies [RQ-0036](../requirements/rq-0036.md) AC-1 and AC-4 through the running application,
using worktree.spec's relaunch pattern: the build's session dies with the app, the worktree and
its checkpoints survive, and Resume picks the story up with the stub agent.

## Steps

1. Start a worktree build with the stub agent and let it checkpoint, then relaunch the
   application. Expect the worktree and its checkpoints on disk and the build's row shown as
   resumable — no session state survived, and none is needed.
2. Press Resume on the row. Expect a fresh stub session attached in the surviving worktree,
   prompted from its checkpoints, and the row live again.
3. Let the resumed build run a turn. Expect a new checkpoint on the same branch — the build
   continues, not restarts.

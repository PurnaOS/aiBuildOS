# TC-0018 — The workspace lays out three panes with a tabbed centre and streams a turn

Verifies [RQ-0004](../requirements/rq-0004.md) AC-1, AC-2 and AC-3. Playwright against the built
application ([DC-0013](../decisions/dc-0013.md)), with the harness pointed at the scripted stub and
both config files in a temporary directory.

## Steps

1. Open a project. Expect three panes: the record, the conversation, the files.
2. Expect the conversation to be the first tab in the centre and to have no close control.
3. Send a message. Expect the reply to appear progressively rather than all at once, and expect the
   turn to end.
4. Expect a tool call from the stub to be shown with its status in words.
5. Collapse each side pane and expect the conversation to widen; restore them.
6. Close the application and reopen it. Expect the pane widths to be as they were left.
7. Open a file from the files pane. Expect it to open as a further tab, and expect the conversation
   tab to still be there.
8. Open the same file again. Expect focus to move to the tab that is already open, not a second one.

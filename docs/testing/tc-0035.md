# TC-0035 — The sidebar collapses, comes back, and is remembered

Verifies [RQ-0009](../requirements/rq-0009.md) AC-1 to AC-3, and [BG-0004](../bugs/bg-0004.md) with
it — [RQ-0004](../requirements/rq-0004.md)#AC-1's promise that a layout survives a restart.

The restart is the part worth writing down: a toggle that forgets is a toggle that has to be pressed
every morning, which is a slower version of the problem it was added to solve.

## Steps

1. Collapse the sidebar. Expect it to take no width, and a handle to be on screen in its place.
2. Restore it from that handle. Expect it back — an affordance that exists only as a keystroke is one
   most people never find.
3. Toggle it by the Sidebar command, which is what ⌘B is attached to.
4. Leave it collapsed and restart. Expect it still collapsed.
5. Resize a pane and restart. Expect the width kept — the criterion BG-0004 showed was never met.

# TC-0106 — Pressable chrome and honest labels in the running app

Verifies [RQ-0041](../requirements/rq-0041.md) AC-1, AC-2 and AC-4 through the running
application. A native `window.confirm` would hang the driver where a Radix dialog answers it —
the discipline TC-0081 already holds the project-close prompt to, extended to PlanTab's retire.

## Steps

1. Open an artifact that something links to. Press an inbound link in the rail; expect the linked
   artifact to open as a tab.
2. Retire a draft from PlanTab. Expect the application's own dialog in the established Radix
   idiom — answerable by the driver, styled like every other dialog — not a native confirm.
3. Expect the Git pane's two commit actions to read "Commit staged" and "Commit all changes", and
   the review's two send actions to read "Send back to build session" and "Hand to main chat".

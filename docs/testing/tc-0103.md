# TC-0103 — Every session row carries enough to say what it is

Verifies [RQ-0040](../requirements/rq-0040.md) AC-1 and AC-2 at the unit level, against the
session registry behind `session:list`.

## Steps

1. Hold a build session, a background run, and a plain chat. Expect every `session:list` row to
   carry `label` (`string|null`) and `startedAt` (ISO-8601) — all three kinds alike.
2. Derive each row's kind: `storyId` set reads as build, `label` set as task, neither as chat.
   Expect the derivation to hold for all three, and expect no stored kind field on any row or
   registry entry — the shape itself proves kind is computed, never persisted.

# TC-0111 — deriveDock reads the whole inventory

Verifies [RQ-0044](../requirements/rq-0044.md) AC-2, AC-3 and AC-4 at the derivation:
`deriveDock(sessions, builds, backgroundRuns, terminals)` takes the session inventory, not
`build:list` alone. This is the case that fails if the dock is "NowTab moved down".

## Steps

1. Drive `deriveDock` with a main chat mid-turn, worktree builds, a background run, and a
   terminal. Expect all four sections populated — and a chat-only inventory, no worktree build
   anywhere, still to yield the main chat's activity.
2. Drive it with the main chat waiting on the user, a worktree permission request, and a blocked
   background run. Expect the needs-you rollup to count all three — the main chat is not exempt.
3. Feed `nextAction()` competing candidates. Expect the action chosen by its declared priority
   order, not by list position.

# TC-0066 — Worktree verbs create, checkpoint, merge and reconcile

Verifies [RQ-0020](../requirements/rq-0020.md) AC-1 and AC-3 to AC-5 at the Git boundary,
against real repositories.

## Steps

1. Create a worktree for a story. Expect it on `aibuildos/<story>`, branched from HEAD, listed by
   the enumeration.
2. Dirty it and checkpoint. Expect a commit on the branch and a clean worktree; a rejecting hook
   surfaces its words and checkpoints nothing.
3. Merge a clean branch. Expect --no-ff into main, the worktree gone, the branch deleted.
4. Merge a conflicting branch. Expect Git's words back, main untouched, the worktree still there;
   discard removes it without merging.
5. Prune after deleting a worktree directory by hand. Expect the enumeration honest again.

# TC-0012 — Link rules check declared relationships, target types, cardinality and cycles

Verifies [RQ-0003](../requirements/rq-0003.md) AC-8 through AC-11, covering
[ST-0008](../user-stories/st-0008.md) AC-1 through AC-7. Runs on Node under Vitest against a profile
and artifacts built as literals.

## Steps

1. Give an artifact a relationship its type does not declare. Expect one finding at **warning**
   severity.
2. Point a relationship at an artifact whose type it does not accept. Expect an error naming the
   relationship and the type it received.
3. Point a relationship declaring an abstract target at an artifact of a type extending it. Expect no
   finding — polymorphism accepts the subtype.
4. Point a relationship at an artifact whose type the profile does not define, where the relationship
   names that type. Expect no finding.
5. Point a relationship at an ID that does not exist. Expect exactly **one** finding — the
   pre-existing `link/target-exists` — and no target-type finding for the same link.
6. Omit a relationship declared `min: 1` on an artifact past its initial state. Expect an error.
7. Omit the same relationship on an artifact still in its type's initial state. Expect no finding.
8. Exceed a relationship's `max`. Expect an error, in the initial state as well as past it.
9. Build a cycle across three artifacts in a relationship declared `cycles: forbid`. Expect exactly
   one finding, naming the path around the cycle rather than one finding per artifact.
10. Build the same three-artifact chain without the closing edge and expect no finding. Build a
    diamond — two paths converging, no cycle — and expect no finding.

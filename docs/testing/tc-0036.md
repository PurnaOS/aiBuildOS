# TC-0036 — A failed save keeps the work and names the failure

Verifies [RQ-0008](../requirements/rq-0008.md) AC-6 — the one criterion
[TC-0034](tc-0034.md) left uncovered.

The failure is real, not mocked: the file is made read-only, so the refusal comes from the
filesystem and the whole reporting path runs. What matters is what does *not* happen — the editor
does not pretend the write landed, and nothing typed is thrown away.

## Steps

1. Open a file and make it read-only on disk. Type into it and let the autosave fire.
2. Expect the failure named on screen, the tab still saying the work is unwritten, and the file on
   disk untouched.
3. Expect what was typed still in the editor — a failed write must cost nothing but the wait.
4. Make the file writable and save by the Save command. Expect the same kept work — not retyped —
   written to disk, and the failure message gone.

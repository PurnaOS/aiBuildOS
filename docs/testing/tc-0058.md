# TC-0058 — The checks run beside the review, and a failure goes to the agent

Verifies [RQ-0019](../requirements/rq-0019.md) AC-1 to AC-4 through the running application, with
a fixture project whose checks playbook holds one passing and one failing command.

## Steps

1. Open a project with a checks playbook. Expect the checks offered; a project without one offers
   nothing.
2. Run them from a story's review. Expect the output arriving live and each command's verdict in
   words beside the story.
3. Hand the failure to the agent. Expect one visible prompt carrying the failing command and its
   output.

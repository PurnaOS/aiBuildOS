# TC-0076 — What anything writes, the workspace shows, with no turn ending

Verifies [RQ-0026](../requirements/rq-0026.md) AC-1, AC-2, AC-3 and AC-5 through the running
application — the test process is the "terminal".

The renderer does not call `project:open` on the click that opens a project yet, so nothing starts
the watch in the running app today — a gap this story found but is not the one closing (see
ST-0043's coordinator note). The harness reaches `project:open` directly, the same way TC-0039
reaches a channel directly for its refusal case, so what this proves downstream of the watch
starting is still the real pipeline.

## Steps

1. With the workspace idle, write a new file, change an artifact's state on disk, and commit from
   the test process. Expect the tree, the board and the Git tab each to show it within the
   debounce, no turn anywhere — no session is ever started.
2. One refresh per change burst is TC-0075's own claim, proved at the watcher directly; there is no
   way to count a renderer's re-fetches from outside the process it runs in, so this case does not
   re-prove it — it only relies on the turn-end double-refresh being gone, which AC-5 also requires.

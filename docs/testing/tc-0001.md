# TC-0001 — Harness store persists, upserts and survives a bad file

Verifies [RQ-0001](../requirements/rq-0001.md) AC-1, AC-2 and AC-9. Runs on Node under Vitest against a
temporary directory — the store takes its file path as a parameter, so no Electron runtime is needed.

## Steps

1. Load harnesses from a path that does not exist. Expect an empty list, no throw.
2. Save a harness with no ID. Expect a generated ID back and the record on disk.
3. Load again from the same path. Expect exactly that harness, field for field.
4. Save the same harness with its ID and a changed command. Expect one record, not two, with the new
   command.
5. Save a second harness. Expect two records.
6. Remove the first by ID. Expect only the second to remain.
7. Write `not json at all` into the file and load. Expect an empty list, no throw.
8. Truncate a file holding three harnesses, then save and remove. Expect both to throw, and the file
   to be byte-for-byte unchanged.

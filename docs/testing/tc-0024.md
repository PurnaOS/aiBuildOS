# TC-0024 — Saving an artifact rewrites only what changed, and the index with it

Verifies [RQ-0005](../requirements/rq-0005.md) AC-8 and AC-10, for the frontmatter half of AC-8 and
for the index. Vitest against the writer directly —
this is a property of the bytes, and the interface is not where it can be proved.

The last case is the one that carries the weight: it edits a document this bundle actually contains,
comments, blank lines and all, and asserts the result equals the original with one substring replaced.
A fixture can be written to suit the writer; a real artifact cannot.

## Steps

1. Change one field. Expect the whole file to be identical but for that field's value.
2. Expect a quoted title to stay quoted and an inline map to stay inline.
3. Set one entry under `links:`. Expect its neighbour and `tags:` untouched.
4. Replace the body. Expect the frontmatter byte-identical.
5. Ask for nothing. Expect the source back unchanged.
6. Set a value that would change meaning unquoted. Expect it quoted.
7. Offer a CRLF document. Expect a refusal rather than a silently normalised file.
8. Set a key that is not there and nobody vouched for. Expect a refusal rather than an invented key.
9. Create a key the caller **did** vouch for. Expect it inserted, and everything else identical.
10. Take a real artifact from `docs/`. Expect exactly one substring to differ.
11. Set a state in a directory index. Expect that row's other cells, and every other row, unchanged.

# TC-0117 — Scaffolding writes valid guardrail hooks, and only where they belong

Verifies [RQ-0049](../requirements/rq-0049.md) AC-1 and AC-3 at the scaffolding seams: create
writes the hook files, re-seed adds missing ones without overwriting, an unsupporting harness
gets instructions only.

## Steps

1. Run `bun run test` filtered to `scaffold.test.ts` and `playbooks.test.ts`.
2. Expect: creating with a hook-supporting harness writes its hook config beside
   AGENTS.md/CLAUDE.md, and the written JSON parses; re-seeding a project that has AGENTS.md but
   no hooks adds only the hooks; re-seeding a project with edited hooks leaves them untouched;
   a harness without hook support produces no hook file and no error.

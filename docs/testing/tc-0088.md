# TC-0088 — The sync header shows the branch and its counts

Verifies [RQ-0033](../requirements/rq-0033.md) AC-1 and AC-4 through the running application:
the slim sync header atop the FilesRail git pane, against the same bare origin
[TC-0086](tc-0086.md) sets beside the temp project.

## Steps

1. Open the git pane. Expect the sync header naming the current branch with its ahead/behind
   counts and offering Push and Pull.
2. Commit locally. Expect the ahead count to rise without a refresh being pressed.
3. Push. Expect the counts to return to even, again unprompted — the header follows the facts
   the watcher already carries.

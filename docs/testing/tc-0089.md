# TC-0089 — pr.ts maps gh output and its absence

Verifies [RQ-0034](../requirements/rq-0034.md) AC-1, AC-2 and AC-4 at the unit level: the JSON
mapping in `main/pr.ts` and the ENOENT path, driven through the `AIBUILDOS_GH_BIN` seam so no
real `gh` is ever required.

## Steps

1. Point the seam at a stub that prints `gh pr view --json` output for an open PR. Expect the
   mapped result carrying the PR's number and state.
2. Expect the invocation to be argv-only — the exact `["pr", "view", "--json", …]` argument
   vector, no shell, no token material anywhere in env or argv beyond the user's own ambient
   auth.
3. Point the seam at a path that does not exist. Expect ENOENT to come back as
   `{ok: false, code: "gh_missing"}` — data, not a thrown error.
4. Feed the stub a non-zero exit with stderr. Expect a not-ok result preserving the words rather
   than a crash.

# TC-0027 — The rails show what the agent and the user just changed

Verifies [BG-0001](../bugs/bg-0001.md) and [RQ-0004](../requirements/rq-0004.md) AC-14 and AC-15.

The regression is the interesting part: both rails read once and never again, so an agent could write
the first requirement of a project and the rail would go on saying there were none. The check has to
watch the rail across a turn rather than after a reload, because a reload has always worked.

## Steps

1. Open a project whose bundle has no artifacts. Expect the record rail to say so.
2. Expand a directory in the file tree, so there is something already open to go stale.
3. Write an artifact and its index row while a turn is running, and let the turn finish.
4. Expect the record rail to list it, without reopening the project.
5. Expect the expanded directory to list the new file, still expanded.
6. Expect the Git tab to report it as an untracked change.
7. Change an artifact's state in an editor tab and save. Expect the rail to show the new state.

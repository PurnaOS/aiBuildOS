# TC-0123 — Commands sit beside playbooks, and the list is alive

Verifies [RQ-0051](../requirements/rq-0051.md) AC-1 and AC-3 through the running application.

## Steps

1. Run `bun run test:e2e` filtered to the controls spec (build first).
2. Expect: the composer's menu shows a Commands group beside Playbooks, carrying the stub's own

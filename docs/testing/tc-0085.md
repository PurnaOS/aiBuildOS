# TC-0085 — The sync verbs against a local bare origin

Verifies [RQ-0032](../requirements/rq-0032.md) AC-2, AC-3 and AC-4 at the unit level: the
`fetch`, `pull` and `push` verbs in `git.ts` against a bare-repo fixture standing in as
`origin`, plus the `toGitError` regexes from canned stderr — no network, no credentials, real
git.

## Steps

1. Clone from a local bare origin, commit ahead, `push`. Expect the commit on the origin's
   branch.
2. Push a branch with no upstream. Expect the `-u origin <branch>` retry to publish it and set
   the upstream.
3. Advance origin and the clone divergently, then `pull`. Expect `--ff-only` to fail with git's
   own stderr preserved — no merge, no rebase.
4. Advance only origin, then `pull`. Expect a clean fast-forward.
5. Feed `toGitError` canned stderr for an authentication failure and a missing remote. Expect
   `git_auth` and `no_remote` respectively, each with the stderr carried alongside.

# TC-0093 — A sprint build bases, merges and reviews against the sprint branch

Verifies [RQ-0035](../requirements/rq-0035.md) AC-2 at the unit level: `branchFor` with a
`sprintId`, the sprint branch as base, and the merge and review paths routing to the sprint's
worktree — against a fixture repo, no application running.

## Steps

1. `branchFor(storyId, sprintId)`. Expect `aibuildos/sp-NNNN--st-NNNN`; without a `sprintId`,
   the plain `aibuildos/st-NNNN` unchanged.
2. `startBuild` with a `sprintId` whose worktree lives. Expect the story branch created from the
   sprint branch's tip, not from main.
3. `startBuild` with a `sprintId` whose worktree is missing. Expect the `no_sprint` refusal.
4. Commit on the story branch, then `mergeBuild`. Expect the merge landing on the sprint branch
   in the sprint's worktree — main unmoved.
5. `reviewBase` for the sprint story. Expect the sprint branch, so the review diff reads against
   the sprint, not against main.

# TC-0009 — The bundle loader walks a bundle permissively and summarises it by type and state

Verifies [RQ-0002](../requirements/rq-0002.md) AC-8. Runs on Node under Vitest against a fixture
directory built in a temporary location.

The loader is the walker that used to live inside the `docs:check` CLI, moved into the knowledge
engine so the app and the CLI read a bundle the same way — the engine is the only code that parses
`docs/` (AR-0002). Permissive consumption is the behaviour under test: anything that is not an
artifact is skipped, never thrown on.

## Steps

1. Walk a fixture bundle containing artifacts, a `README.md` in each directory, a `profile/`
   directory, and a prose file with no frontmatter.
2. Expect every artifact collected, with its directory and basename.
3. Expect `profile/` skipped entirely — it holds type definitions, not artifacts.
4. Expect each `README.md` collected as an index rather than as an artifact.
5. Expect the frontmatter-less prose file skipped without an error.
6. Expect a file whose frontmatter will not parse to be reported as a parse error *and* still present
   in the artifact list, so a validator can report it rather than dropping it.
7. Expect reported paths to be relative to the base passed in, so the CLI's output is unchanged by
   the move.
8. Summarise the bundle. Expect counts by `type` and by `state`, and expect an empty bundle to
   summarise as zero artifacts rather than to fail.

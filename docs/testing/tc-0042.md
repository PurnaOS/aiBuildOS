# TC-0042 — Findings ride the record read, per artifact

Verifies [RQ-0012](../requirements/rq-0012.md) AC-1 and AC-3 at the channel: the workspace's
record read carries each artifact's findings, distinguishing severity, recomputed on every read.

## Steps

1. Read the record of a fixture project holding one artifact with an error, one with a warning,
   one clean. Expect per-artifact error/warning counts attached to the right artifacts, none on
   the clean one.
2. Fix the erroneous file on disk and read again. Expect its findings gone.

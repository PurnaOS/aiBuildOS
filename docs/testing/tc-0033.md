# TC-0033 — A file is made from the tree, in the directory pointed at

Verifies [RQ-0006](../requirements/rq-0006.md)#AC-9.

The menu is native, which is precisely what makes it awkward to drive: Playwright cannot click an
operating-system menu. So the menu's *decision* is asserted through the channel that produces it, and
what follows the decision is asserted through the interface — which is the honest division, since the
platform is responsible for the part that cannot be reached.

## Steps

1. A folder's own path is what its menu acts on; a file's is the folder it sits in; a file at the
   root is the project itself.
2. Right-click a row with the platform's answer scripted. Expect the create flow to start in the
   directory it named, asking for a name rather than a path.
3. Complete the flow with a name only. Expect the file written inside that directory, in the tree, and
   open in the centre.
4. Right-click with a dismissal scripted. Expect no form, and nothing written.

That the operating system draws a menu when asked is not asserted, and cannot be from here: Playwright
cannot click one. What is asserted is the wiring either side of it.

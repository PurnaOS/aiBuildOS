# TC-0034 — Editing saves itself, except when something else has a claim on the file

Verifies [RQ-0008](../requirements/rq-0008.md) AC-1 to AC-5, AC-7 and AC-8.

The suppressions are what this is really for. A timer that writes whatever is in the editor is easy;
one that knows to keep its hands off while the agent is mid-turn, or while a person is being asked
which version to keep, is the thing that can silently destroy work if it is wrong.

## Steps

1. Type into a file and stop. Expect the file on disk to match, with nothing pressed.
2. Type a burst without pausing. Expect one write, of the last of it, not one per keystroke.
3. Type while a turn is streaming. Expect nothing written for as long as it streams.
4. End the turn. Expect what was typed to be written, after the file has been reconciled with what the
   agent did.
5. Put the conflict bar up and type. Expect nothing written until the choice is made.
6. Invoke the Save command with something unsaved. Expect it written at once rather than at the end
   of the pause. The **accelerator** is not pressed: a synthetic key press cannot fire a native one,
   so what is exercised is everything the accelerator is attached to.
7. Expect the menu to still carry copy, paste, undo, select-all and quit — setting a menu at all costs
   the platform's own, and adding ⌘S at the price of ⌘C would be a poor trade.
8. Expect no Save button anywhere.
9. Close a tab that was just typed into and settled. Expect no question, and the typing on disk.
10. Expect a tab whose write is being held back to say so, which is the one case where closing would
    lose something.

# TC-0079 — The scaffold seeds the instructions, and the seeder never overwrites

Verifies [RQ-0028](../requirements/rq-0028.md) AC-1 to AC-3 at the scaffold and seed action.

## Steps

1. A created project carries root AGENTS.md and CLAUDE.md; the CLAUDE.md is the import line; the

2. Seeding an adopted project adds both; seeding again — or against a project with its own
   CLAUDE.md — overwrites nothing.

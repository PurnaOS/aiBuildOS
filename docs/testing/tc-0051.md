# TC-0051 — A question fence becomes a card, and a broken one becomes text

Verifies [RQ-0016](../requirements/rq-0016.md) AC-1 and AC-5 at the parser: the pure split of a
completed message into prose and question.

## Steps

1. Parse a message holding prose around a well-formed question fence. Expect the prose intact and
   the question's text, options and free-text flag extracted.
2. Parse malformed JSON in the fence, a fence with no options, and an ordinary code fence. Expect
   plain text back in every case — never a throw, never a half-question.

# TC-0094 — Two sprint stories build side by side and land on the sprint

Verifies [RQ-0035](../requirements/rq-0035.md) AC-2 and AC-4 through the running application:
two stories of one sprint building in parallel worktrees off the sprint branch, both merges
landing on it, main never moving.

## Steps

1. Start a sprint with two ready stories, then build both. Expect two live worktrees on
   `aibuildos/sp-NNNN--st-NNNN` branches, each based on the sprint branch's tip.
2. Drive both stub builds to review and accept each merge. Expect both merges on the sprint
   branch and main's tip unmoved.
3. While the stories flip states, compare the sprint branch's `docs/` to its base. Expect it
   byte-identical — the flips happened in the main checkout, and the boards still show them.

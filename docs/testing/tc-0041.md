# TC-0041 — Moving a card is the state change, and an illegal drop is a refusal

Verifies [RQ-0011](../requirements/rq-0011.md) AC-2 to AC-4, AC-6 and AC-7 through the running
application, asserting against the files on disk — the board claims to be a view of them.

## Steps

1. Open the Board tab. Move a draft requirement's card to ready — by the card's menu, the twin
   every drag must have. Expect the file's frontmatter flipped and the index row with it.
2. Attempt an illegal move. Expect the refusal in words, the card unmoved, the file untouched.
3. On the Work view, expect the builders' columns to accept no moves, saying why; expect a
   review story movable to accepted.
4. Change a state on disk directly and refresh the workspace. Expect the card in its new column.
5. Click a card. Expect its artifact open as a tab.

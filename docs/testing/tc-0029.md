# TC-0029 — A minted artifact is what its type says it is

Verifies [RQ-0006](../requirements/rq-0006.md) AC-2, AC-3 and AC-4. Vitest against the scaffolder.

The failure this guards against is a document that looks like an artifact and is not one — a missing
required field, a body without the section its type declares, a number already in use. The strongest
case is the last one: what is scaffolded is fed straight back to the validator, which is the only
authority on whether it is an artifact.

## Steps

1. Allocate an ID for a prefix the bundle already uses. Expect one above the highest, whatever the
   gaps below it.
2. Allocate for a prefix nothing uses yet. Expect `0001`.
3. Scaffold a Requirement. Expect the common frontmatter, the type's own required fields, and the
   body sections the type declares.
4. Expect `provenance: human` and no `generated` block: nobody generated it.
5. Scaffold a type with no required fields of its own. Expect no invented ones.
6. Validate what was scaffolded against the profile. Expect no findings.
7. Insert an index row. Expect it appended to the table, the header and every existing row untouched.
8. Insert into an index whose table is empty. Expect the row to be the first.

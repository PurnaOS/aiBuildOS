# TC-0003 — ACP probe reports each failure stage and always reaps the child

Verifies [RQ-0001](../requirements/rq-0001.md) AC-7 and AC-8. A test button whose only outcomes are
"works" and "something went wrong" is not worth pressing; each failure has to name its own stage.

## Steps

1. Probe a command that is not on `PATH`. Expect `ok: false`, stage `spawn`, and a code identifying a
   missing command.
2. Probe a command that exits immediately without speaking. Expect `ok: false`, stage `initialize`,
   and the process's stderr carried in the result.
3. Probe the stub agent scripted to never answer, with a short timeout. Expect `ok: false` and a
   timeout code, returned within the timeout budget rather than hanging.
4. Probe the stub agent scripted to fail `session/new` with an authentication-required error. Expect
   `ok: false`, stage `session`, code `auth_required`, and the advertised authentication methods.
5. Probe with a working directory that does not exist. Expect `ok: false` and a code naming the
   working directory, not the command.
6. Probe a launcher that backgrounds a marker process and `exec`s a silent agent — the `npx` shape —
   and let it time out. Expect no surviving marker process.

# TC-0015 — A session stays open across prompts, streams every update kind, and cancels cleanly

Verifies [RQ-0004](../requirements/rq-0004.md) AC-4, AC-11 and AC-17. Runs on Node under Vitest
against the scripted stub agent, never a live model ([DC-0013](../decisions/dc-0013.md)) — which is
why the stub grows the update kinds this case needs.

## Steps

1. Open a session against the stub. Expect the handshake to complete and a session id to come back.
2. Send a prompt. Expect the streamed updates to arrive in order and the turn to end.
3. Send a second prompt on the same session. Expect it to be answered **without** the agent being
   spawned again.
4. Expect the stub's tool call, its update, its diff and its plan all to be delivered — not only the
   message text.
5. Cancel a turn in progress. Expect the cancel notification to be sent, expect updates that arrive
   after it to still be delivered, and expect the turn to end as cancelled rather than as failed.
6. Close the session. Expect the agent process and any process it spawned to be gone.
7. Point a session at a command that does not exist. Expect a named failure, not a thrown error.
8. Prompt a session that was never opened. Expect a named failure.

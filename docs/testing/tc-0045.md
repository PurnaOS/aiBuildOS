# TC-0045 — A pressed playbook says exactly what it sent, in the transcript

Verifies [RQ-0013](../requirements/rq-0013.md) AC-2 to AC-5 through the running application,
against the stub agent's `echo` mode — which replies with the prompt it received, so the
transcript shows both what was sent and proof of what arrived.

## Steps

1. Open a scaffolded project. Expect the standard playbooks present as buttons.
2. Inspect a button before pressing. Expect its description, its harness, and its exact text.
3. Press it. Expect the composed prompt in the transcript as the user's message, and the echo
   back.
4. Edit the playbook artifact's body and press again. Expect the new text sent, with no
   application change.
5. Open a project without playbooks. Expect no buttons and the offer to seed the standard set;
   accept it and expect the buttons.

# TC-0055 — Stage, unstage and commit run the user's own Git

Verifies [RQ-0018](../requirements/rq-0018.md) AC-1 to AC-3 and AC-6 at the Git boundary, against
real repositories in temp directories.

## Steps

1. Stage a path, unstage it, stage it again and commit with a message. Expect the status counts
   to follow each step and the commit in the log.
2. Install a pre-commit hook that rejects. Expect the hook's own words in the reported failure
   and the work still staged.
3. Expect every invocation to be argv — no shell interprets anything anywhere.

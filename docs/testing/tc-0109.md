# TC-0109 — The + menu composes what the strip composed

Verifies [RQ-0043](../requirements/rq-0043.md) AC-1 at the module level: the composer's `+` menu
is a new offering of the same composition, not a new composition. `derivePlaybooks` and
`compose()` are unchanged; this case pins the menu model to their output.

## Steps

1. Build the `+` menu model. Expect a Playbooks section listing exactly what `derivePlaybooks`
   derives and a Commands section listing exactly the agent's advertised commands — the same
   entries the strip and the COMMANDS chip offered.
2. Choose a playbook and a command from the menu. Expect the composed prompt byte-identical to
   what the strip or chip would have composed for the same choice.

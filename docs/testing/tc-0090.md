# TC-0090 — The PR chip with and without gh

Verifies [RQ-0034](../requirements/rq-0034.md) AC-1, AC-2 and AC-3 through the running
application. The absent path is the one CI actually exercises for real — runners carry no
authenticated `gh` — and the present path rides an `AIBUILDOS_GH_BIN` stub script, so both
halves run everywhere.

## Steps

1. Launch with the seam unset on a machine without `gh` (the CI truth). Expect the chip quiet
   and no error anywhere — absence is data.
2. Launch with `AIBUILDOS_GH_BIN` naming a stub script that answers as `gh` would for an open
   PR. Expect the sync header's chip showing the PR's number and state after the status is asked
   for.
3. Watch the stub's invocation count across idle time. Expect exactly the on-demand calls and no
   more — no polling loop exists.

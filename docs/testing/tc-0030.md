# TC-0030 — A file and an artifact are started from the workspace

Verifies [RQ-0006](../requirements/rq-0006.md) AC-1, AC-5, AC-6, AC-7 and AC-8. Playwright against
the built application.

What this proves that [TC-0029](tc-0029.md) cannot is that the types offered come from the project in
front of the user rather than from this repository's own vocabulary, and that the refusals are
refusals — nothing half-written left behind.

## Steps

1. Create a file at a path given by the user. Expect it on disk, empty, and in the tree without a
   reload.
2. Create a file at a path that already exists. Expect a refusal, and the existing file untouched.
3. Create a file at a path that climbs out of the project. Expect a refusal, and nothing written.
4. Mint an artifact by choosing a type and a title. Expect the file, the index row, and the artifact
   open in the centre showing what was typed.
5. Expect the types offered to be the ones the project's own profile declares, and not to include an
   abstract one.
6. Open a project with no profile. Expect it to say artifacts cannot be minted there, and to offer no
   types.
7. Open a project whose repository has no configured identity. Expect minting to be refused, naming
   the missing setting, with nothing written.

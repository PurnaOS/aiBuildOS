# TC-0008 — A project is created, listed, opened and closed from the launch page

Verifies [RQ-0002](../requirements/rq-0002.md) AC-2, AC-6 and AC-10. Playwright against the built
Electron app ([DC-0013](../decisions/dc-0013.md)), with both the projects file and the harnesses file
pointed at a temporary directory.

The native directory picker cannot be clicked by a test, so the test replaces
`dialog.showOpenDialog` inside the main process for the duration of the run. That keeps the real
picker on the real code path in production — there is no test-only branch in the handler — while still
exercising the whole create flow end to end. It is also why `ipc.ts` must call the dialog as a
property of `dialog` rather than destructuring the function out of it.

A harness is pre-written into the temporary harnesses file because the first-run attach dialog from
[TC-0004](tc-0004.md) is modal and would otherwise cover the launch page.

## Steps

1. Launch with an empty projects file. Expect the launch page, and expect its empty state to offer
   both ways to add a project.
2. Stub the native directory picker to answer with a temporary directory.
3. Create a project named `demo`. Expect one row on the launch page, showing the branch Git chose and
   a clean working tree.
4. Open it. Expect the workspace: the record on the left, the conversation in the centre, the files
   on the right — and expect its bundle to report no artifacts, which for a new project is correct
   rather than an error.

   This step originally expected a status page showing branch, commits and record counts.
   [ST-0011](../user-stories/st-0011.md) replaced that page with the workspace and moved those
   readings onto the Git tab of the right rail, so the step follows the product rather than the
   product quietly drifting from the step.
5. Close the project. Expect the launch page again, without a restart.
6. Close the application and relaunch against the same projects file. Expect the row to still be
   there — the registry survives a restart.
7. Rename the project's directory on disk, then reload. Expect the row to be listed as unavailable
   with its path, expect the launch page to still function, and expect forgetting it from the row to
   leave the renamed directory on disk.

# TC-0031 — The editors follow the window's appearance

Verifies [BG-0003](../bugs/bg-0003.md) and [RQ-0004](../requirements/rq-0004.md)#AC-1.

Against the rendered editor rather than the extension list, and in both appearances: a fix that forced
dark would be the same defect pointing the other way. Both an ordinary file and an artifact's markdown
panel are checked, because they are separate call sites and only one of them being passed a theme is
exactly the kind of thing that ships.

## Steps

1. Open a file with the window dark. Expect the editor's ground to be the application's dark, not
   white.
2. Expect its text to be legible against that — a light foreground, not the light theme's near-black.
3. Open an artifact. Expect its body panel to be the same.
4. Switch the window to light. Expect both to follow, without reopening either.

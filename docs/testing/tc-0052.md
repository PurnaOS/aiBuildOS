# TC-0052 — A tap answers the agent, and typing answers it too

Verifies [RQ-0016](../requirements/rq-0016.md) AC-1 to AC-4 through the running application,
against the stub agent's `question` mode — which asks one fenced question and echoes back
whatever answer arrives.

## Steps

1. Prompt the stub. Expect its question as a card offering exactly its options, in its wording.
2. Tap one. Expect the answer in the transcript as an ordinary message, and the stub's echo of it.
3. Ask again; type instead of tapping. Expect the typed answer to reach the agent the same way.
4. Ask again; answer nothing. Expect the conversation still usable, the card still there.

# TC-0086 — Push, publish and pull through the interface

Verifies [RQ-0032](../requirements/rq-0032.md) AC-1, AC-3 and AC-6 through the running
application, against a bare origin created beside the temp project — the remote is a directory,
so the user's real credential chain is never in play and CI needs none.

## Steps

1. Open the project and wait. Expect no traffic to the origin until a sync action is pressed —
   nothing fetches or pushes on its own.
2. Commit, then press Push. Expect the commit on the bare origin's branch.
3. Press Push on a branch with no upstream. Expect the publish retry to land it and the branch
   to gain an upstream.
4. Advance the origin from outside, then press Pull. Expect the new commit in the workspace, and
   the git surfaces reflecting the moved refs within the watcher's debounce with nothing further
   pressed.

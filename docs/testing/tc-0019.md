# TC-0019 — The rails list the record with derived links, and the working tree as Git sees it

Verifies [RQ-0004](../requirements/rq-0004.md) AC-14, AC-15 and AC-16, against a temporary project
containing a small bundle and a real repository.

## Steps

1. Open a project whose bundle holds a requirement, a story implementing it and a test verifying it.
2. Expect the record pane to list them grouped by type, each with its ID, title and state.
3. Expand the requirement. Expect the story and the test to be shown against it, although neither is
   named in the requirement's own links.
4. Expect a project with no bundle to say so rather than to show an error.
5. Switch the right pane to Git. Expect a modified file under unstaged, an unknown file under
   untracked, and recent commits listed.
6. Expect a path the repository ignores not to be listed in the file tree.
7. Expand a directory. Expect its children to be read then, and expect an unexpanded directory's
   children not to have been read.

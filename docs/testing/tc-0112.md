# TC-0112 — The dock is everywhere, and it moves

Verifies [RQ-0044](../requirements/rq-0044.md) AC-1, AC-4 and AC-5 through the running
application. The load-bearing assertion is the last one: a turn running in the main chat is
visible from any surface, which kills the "did it land in Chat?" guess Now could never answer.

## Steps

1. Walk every surface — Chat, Plan, Work, and an open document tab. Expect the collapsed dock on
   each of them.
2. Run a main-chat turn from another surface. Expect the collapsed motion line to reflect it as
   it happens, and the expanded Main chat section to show the current turn's activity — no
   switching to Chat to find out.
3. With a story waiting in review, expect the next-action line to carry a real button — "ST-…
   waits in review → [Review]" — and pressing it to open that review.

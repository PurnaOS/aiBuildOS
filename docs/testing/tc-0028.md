# TC-0028 — The conversation is drawn in the application's palette

Verifies [BG-0002](../bugs/bg-0002.md) and [RQ-0004](../requirements/rq-0004.md)#AC-1.

Asserted against the **rendered** surface rather than the stylesheet, because the failure this covers
is a cascade one: the declarations exist and lose. Both appearances are checked, since a fix that
merely forces dark would be the same defect pointing the other way.

## Steps

1. Open a project with the system set to dark. Expect the conversation's surface to be the
   application's dark ground, not white.
2. Expect its text to be the light foreground that goes with it.
3. Switch the system to light. Expect the conversation to follow, to white.
4. Expect no class or attribute on the document saying which appearance is in force — the media query
   is the only thing that decides.

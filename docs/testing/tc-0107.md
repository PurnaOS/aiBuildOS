# TC-0107 — The popover groups by origin and never dedupes

Verifies [RQ-0042](../requirements/rq-0042.md) AC-1 and AC-2 at the component level: one popover
carries every agent setting, grouped by origin, and a name collision between origins survives
untouched — origin disambiguates, so nothing is renamed, deduped, or guessed at.

## Steps

1. Render `AgentPopover` with an ACP session mode, a harness's own options, and supervision.
   Expect three groups: Session holding the session mode, the harness's `displayName` verbatim
   heading its options, and supervision inside the same popover.
2. Feed two options that share a name, one from the session mode and one from the harness.
   Expect both rendered under their own group headings — neither renamed, merged, nor dropped.

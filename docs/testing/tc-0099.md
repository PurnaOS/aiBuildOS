# TC-0099 — The terminal registry keeps its books without the native module

Verifies [RQ-0038](../requirements/rq-0038.md) AC-1, AC-4 and AC-6 at the unit level, driving
`main/terminals.ts` against a fake pty-factory. The injection is the point as much as the seam:
per [DC-0026](../decisions/dc-0026.md), node-pty is never top-level-imported, so this suite runs
on Node without the native module ever loading.

## Steps

1. Open a terminal with the fake factory injected. Expect the factory called with the shell from
   `$SHELL` and a cwd resolved from the project registry — the open request carried no path — and
   a registry id (`t1`, then `t2`…) minted.
2. Drive input and fake pty output. Expect input forwarded to the pty and its data surfaced as
   `terminal:data`; a fake exit surfaces `terminal:exit` and drops the entry from
   `terminal:list`.
3. Open terminals across two projects, then `killForProject` one. Expect exactly that project's
   fake ptys killed and delisted, the other's untouched.
4. Fire the `before-quit` path. Expect every remaining fake pty killed.

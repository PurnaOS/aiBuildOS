# TC-0040 — A board is a derivation of the record, and nothing else

Verifies [RQ-0011](../requirements/rq-0011.md) AC-1, AC-5 and AC-8 as a pure function from a
loaded record to columns of cards.

## Steps

1. Derive boards from a record fixture. Expect columns matching the profile vocabularies and
   every artifact in the column its state names.
2. Expect column order by priority then ID, and the same output for the same input every time —
   there is nothing else the output could depend on.
3. Derive from a record with an unknown state. Expect the artifact surfaced rather than lost.

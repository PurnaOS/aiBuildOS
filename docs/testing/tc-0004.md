# TC-0004 — First launch with no harness prompts the user to attach one

Verifies [RQ-0001](../requirements/rq-0001.md) AC-3, AC-4 and AC-10. Playwright drives the built Electron
app ([DC-0013](../decisions/dc-0013.md)); the harness file path is pointed at a temporary directory
so the run is deterministic.

## Steps

1. Launch the built app with the harness file pointed at an empty temporary path.
2. Expect the attach-harness dialog to be visible.
3. Choose a preset. Expect the command and argument fields to be prefilled and editable.
4. Replace them with the stub agent's command and save.
5. Expect the dialog to close and the harness to appear in the settings list.
6. Relaunch the app against the same harness file. Expect the dialog not to appear.
7. Remove the harness from settings. Expect the dialog to reappear without a restart.
8. Save a harness while the harness file is unwritable. Expect the failure to be shown in the form
   rather than the dialog silently returning to its idle state.

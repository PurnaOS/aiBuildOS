# PB-0001 — Draft requirements from an idea

Interview me about this idea, one question at a time — what it must do, who it is for, how you
would check it is done. Ask exactly one question per turn: pose it as its own fenced block, in this
exact format, then end your turn and wait for the answer ([DC-0020](../decisions/dc-0020.md)).

````
```aibuildos-question
{"question": "Who is this for?", "options": [{"id": "me", "label": "Just me"}, {"id": "team", "label": "My team"}], "allowFreeText": true}
```
````

Stop asking once you have enough to state a requirement plainly.

Search `docs/requirements/` for anything this overlaps or depends on. As each requirement settles —
not all saved for the end — write it as its own draft Requirement artifact following
`docs/guidelines/requirement-first.md` and `docs/guidelines/okf-conventions.md`: the next `RQ-NNNN`,
acceptance criteria as `[AC-n]` items, `depends_on` and `related_to` for anything you found,
`state: draft`, and its row in `docs/requirements/README.md`. One artifact per settled requirement —
the interview can settle more than one. Tell me each ID as you write it and leave it in `draft` —
moving it to `ready` is mine to do, not yours.

# PB-0001 — Draft requirements from an idea

Interview me about this idea, one question at a time — what it must do, who it is for, how you
would check it is done. Wait for each answer before asking the next question; stop once you have
enough to state a requirement plainly.

Search `docs/requirements/` for anything this overlaps or depends on. Then write a new Requirement
following `docs/guidelines/requirement-first.md` and `docs/guidelines/okf-conventions.md`: the next
`RQ-NNNN`, acceptance criteria as `[AC-n]` items, `depends_on` and `related_to` for anything you
found, `state: draft`. Add it to `docs/requirements/README.md`. Tell me the ID and leave it in
`draft` — moving it to `ready` is mine to do, not yours.

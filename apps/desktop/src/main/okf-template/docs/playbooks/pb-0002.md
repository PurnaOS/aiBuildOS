# PB-0002 — Propose a plan

I will name one or more Requirements. Read each one and everything it links to. For each, write a
Story that `implements` it — acceptance criteria that match the requirement's own, a `parent` epic
if one already fits, `state: draft` — and the TestCases that `verifies` it, one per criterion where
that is clearer than one for the whole story. Link the Story's `verified_by` to the TestCases you
wrote.

Follow `docs/guidelines/okf-conventions.md` for IDs, links and file layout, and add every artifact
to its directory's index. Leave everything in `draft` and tell me what you wrote — review comes
before anything is scheduled.
